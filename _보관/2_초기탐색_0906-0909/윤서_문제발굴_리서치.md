## 2-2. 관광 특유의 문제 : 관광객이 와도 골목상권에는 안 온다

- 관광 소비가 **일부 유명 관광지·대형 프랜차이즈에 집중**되면서, 방문객이 늘어도 전통시장·골목상권의 체감 매출 증가는 제한적
- 외국인은 **검색·지도·SNS·리뷰로 목적지를 미리 정하고 오기 때문에**, 검색 결과와 추천 콘텐츠에 노출되지 않는 가게는 관광객 증가를 체감하지 못함
- 지역사랑상품권은 **주민 소비 순환에는 효과적이나 외부 방문객 소비를 새로 유치하는 기능에는 한계**
  → [CBC뉴스, "관광객 늘어도 지역상권은 왜 어려울까…윤영석 의원이 제시한 해법" (2026.07.09)](https://www.cbci.co.kr/news/articleView.html?idxno=587732)

**→ 문제 정의②** : 관광 소비는 **'많이 오는 곳'에 다시 쏠린다.** 유동인구·체류시간이 이미 확보됐는데도 소비로 전환되지 않는 **'숨은 수요 상권'** 이 통계적으로 존재하지만, 아무도 그걸 찾아내지 않는다. ← **아이디어 5의 정확한 자리**

## 2-5. 정책 문제③ : 기존 상권분석 도구는 '관광 수요'를 못 본다

| **Life-Integrated Tourism / 하이퍼로컬 · 데일리케이션** | 관광객이 '명소'가 아니라 '동네 일상'을 소비 → 골목상권이 곧 관광 인프라 |
| **알뜰 + 플렉스 (소비 양극화)** | 1인당 소비 감소 국면에서 **'어디에 쓰나'가 더 중요** → 업종별 기회지수의 필요성 |
| **Dynamic Spatial Experience (가변형 공간)** | 기회지수 하위 활용: 폐업 유휴공간 → 데이터 기반 팝업 전환 |

## 2-8. 아이디어 5 재정의 (제안)

> **[문제] 관광객이 늘어난 상권에서도 소상공인은 죽고 있다. 소상공인 데이터에는 관광객이 없고, 관광 데이터에는 상권이 없기 때문이다.**

# 4. 조사하면서 나온 추가 제안 (팀 회의용)

### 제안 A. ★ 5번 + 6번을 하나로 합치기 — 「축제 → 상권 소비 전환율(Conversion Rate)」
지금 5번과 6번은 **따로 내면 둘 다 애매하지만, 합치면 유일무이한 지표**가 됩니다.
- 축제 예산 → 축제장 내부 소비 → **축제장 반경 밖 상권 소비**로 얼마나 흘렀는가
- 이 '전환율'이 낮은 축제 = 예산이 새는 축제 / 높은 축제 = 상권 연계 설계가 잘된 축제
- 근거: 방문객은 +21.1%인데 일평균 지역 소비 증가는 +1.5%p → **전환율이 무너졌다는 직접 증거**
- 강진 반값여행이 대상을 받은 이유가 정확히 "관광 소비를 상품권·농특산물로 **환류**시켰다"는 점 → 심사위원 취향 적중

### 제안 B. '무료 축제의 역설' 단독 분석
- 데이터랩 축제 긍정 키워드 **'무료' 2위 급부상** vs **1인당 소비 -17%**
- "무료화로 방문객 KPI는 채우고 소비 KPI는 버리는" 지자체 행태를 데이터로 증명 → **뉴스성이 매우 높음**

### 제안 C. 반값여행 확대의 그림자 — 환급 소비의 업종 쏠림
- 반값여행 소비: **식음료 45.5% / 숙박 32.2% / 쇼핑·특산품 10.2% / 관광·체험 6.3%**
- 즉 **77.7%가 먹고 자는 데 쓰이고, 지역 고유 콘텐츠(체험)에는 6.3%만** 감
- 문체부가 2026년에 이 사업을 **확대**하는 중이므로 → **"확대 전에 업종 배분을 데이터로 설계하자"** 는 제안은 타이밍이 완벽함
→ [헤럴드경제 반값여행 성과 기사](https://biz.heraldcorp.com/article/10853526)

### 제안 D. 바가지요금 자동탐지 지표 (아이디어 6의 서브 모듈)
- 정부가 사람 보내서 잡는 걸, 데이터랩 결제단가로 자동 탐지
- 제주가 이미 **'바가지 = 지정 제외 + 보조금 삭감'** 제도를 시행 중 → **판정 근거 데이터가 없어서 제도가 못 굴러감** ← 우리가 채울 자리

### 제안 E. '좀비 축제' 지수
- 세계일보 기사에서 이미 **'좀비 축제'** 라는 표현 사용
- 3년 연속 ①1인당 소비 감소 ②주민 참여율 감소 ③외지인 비율 정체 → 자동 리스트업

# 5. 발표 시 방어해야 할 약점 / 추가 확인 필요

1. **관광두레 81% 소멸 수치는 2024년 8월 기사** → 공사가 2024년 하반기 전수조사를 하겠다고 했으므로 **후속 결과 확인 필요**. 발표에선 "이후 전수조사 착수" 사실을 함께 언급해야 공정성 확보.
2. **두 공식 보고서의 1인당 소비액 2배 차이** → 이걸 "자료가 부정확하다"가 아니라 **"표준 산식 부재의 증거"** 로 프레이밍할 것. (실수로 한쪽만 인용하면 심사위원이 반박함)
3. **데이터랩 소비 데이터는 BC+신한 2개 카드사** → 전수(모수)가 아님. 산식에 **보정계수** 를 넣어야 방어 가능. (근거: 심원섭 외 2018 논문)
4. **경제파급효과 산출 시 역외유출(leakage) 반영 필수** → 철원 한탄강 논문 방식 참고.
5. 폐업률 통계는 **국세청 기준(폐업 신고)** 과 **중기부 실태조사 기준** 이 다름 → 인용 시 출처를 반드시 병기.
