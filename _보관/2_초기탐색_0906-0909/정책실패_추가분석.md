# ★ 핵심 발견 — "정부 KPI가 축제를 망치고 있다"

## 근거 문서: 문화체육관광부 「성과관리 전략계획(2024~2028)」

정부업무평가 포털에 공개된 문체부 공식 성과관리 문서입니다. **국가재정법상 의무 문서**이며, 여기 적힌 성과지표가 곧 문체부·한국관광공사가 실제로 관리하는 KPI입니다.
→ [원문 PDF (정부업무평가포털)](https://www.evaluation.go.kr/upload2/atch/eval/20240531165151080.pdf)
→ [직전판: 성과관리 전략계획(2022~2026)](https://evaluation.go.kr/upload2/atch/eval/20230307141915997.pdf)

### 전략목표 Ⅳ「관광」의 성과지표 전체 목록 (원문 그대로)

| 층위 | 성과지표 |
|---|---|
| **전략목표** | 1인당 국내여행 일수(일) · 국내여행 지출액(조원) |
| **성과목표 Ⅳ-1** 관광서비스 기반 선진화 | 국민여행 총량(억일) |
| **성과목표 Ⅳ-2** 인바운드 질적 개선 및 **'지역관광 콘텐츠 확충'** | **K-관광 로드쇼 개최 국가·도시 수(개)** |
| └ 한국형 관광콘텐츠 육성 | 템플스테이 참가자 수(천명) · **문화관광축제 평균 관람객 수(천명)** |
| └ 방한시장 경쟁력 강화 | 3대 전략시장 방한외래객(만명) |
| └ 관광수출 확대 추진 | 한국방문의 해 캠페인 유치 외국인 관광객 수(만명) |
| **성과목표 Ⅳ-3** 관광산업 경쟁력 강화 | 관광/여행 서비스업 생산지수 |
| └ 관광산업 발전기반 조성 | (예비)관광벤처기업 발굴·지원 수(개) · 미래형 관광인재 육성 교육자 수(명) |
| └ 고부가가치 융복합 관광산업 육성 | 개최지원 MICE행사 참가자 수(천명) · 외국인 의료관광객 수(만명) |
| └ 지속가능한 관광개발 추진 | 광역관광자원개발 **공정률(%)** · 관광거점도시 육성사업 **공정률(%)** |

### 이 표에서 읽히는 네 가지 실패

**① 지역 소비·상권·소상공인 매출을 재는 지표가 단 한 개도 없다.**
관광 파트 전문(全文)에서 성과지표에 '상권', '소상공인', '매출'이라는 단어는 한 번도 등장하지 않습니다. ('매출'은 카지노 사행산업 매출총량제 맥락에서만 나옴)

**② 유일한 금액 지표는 '전국 총액'이다.**
`국내여행 지출액(조원)`: '19년 44.2조 → '20년 24.1 → '21년 25.9 → '22년 34.5 → '23년 37.8 → **'28년 목표 50.8조**
→ 전국 합계이므로 **서울·부산·제주 쏠림이 아무리 심해져도 지표는 달성**됩니다. 지역 분배를 재는 장치가 구조적으로 없습니다.

**③ '지역관광 콘텐츠 확충'이라는 목표의 대표 지표가 「해외 로드쇼 개최 도시 수」다.**
목표 문장과 측정 대상이 전혀 연결되지 않습니다. ('23년 15개국 → '26년 30개국 목표)

**④ ★ 문화관광축제의 유일한 공식 KPI = 「평균 관람객 수(천명)」**
소비액도, 주민 참여도, 체류시간도, 재방문율도 아닌 **머릿수**입니다.

> ### 인과 사슬 (발표 첫 장에 쓸 논리)
> **정부 KPI = 관람객 수**
> → 지자체 입장에서 **무료 개방·셔틀 동원으로 머릿수를 채우는 것이 가장 합리적 선택**
> → 실제로 방문객 **1,431만 명(+23.7%)** 달성
> → 그런데 1인당 소비 **−17%**, 외지인 소비 **−18%**, 주민 참가율 **−8.6%p**, 긍정 키워드 2위 **'무료'**
> → **KPI는 달성됐는데 지역은 손해를 봤다.**
>
> 이것은 예산 낭비가 아니라 **지표 설계의 실패(Metric Failure)** 입니다.
> 측정이 목표가 되는 순간 좋은 측정이 아니게 된다 — **굿하트의 법칙**.

**개발사업 지표도 같은 문제**: 광역관광자원개발·관광거점도시 육성사업의 공식 KPI가 **공정률(%)**, 즉 "예산을 계획대로 썼는가"입니다. 관광객이 늘었는지, 지역이 벌었는지는 지표에 없습니다.

## 1-1. 관광거점도시 육성사업 — KDI가 직접 문제를 지적한 사업

- **사업 규모**: 부산(국제관광도시) + 강릉·목포·안동·전주(지역관광거점도시) 5곳, 2020~2025년, **최종 사업비 1,277억 원**

- **KDI 「관광거점도시 육성사업」 타당성 재조사 보고서 (2022.01.31, 정민웅)**
  당초 5개년 1,300억으로 공모했으나 **1년간 KDI 적정성 검토를 거쳐** 2022년 2월에야 사업기간 연장·사업비 확정. 보고서가 지적한 항목:
  - **사업목표의 적절성 및 시급성** 검토 필요
  - **사업수요의 적절성** 검토 필요
  - **비용 추정의 정확성** 문제
  → [KDI 보고서 원문](https://www.kdi.re.kr/research/reportView?pub_no=17490)
  → [KDI 공공투자관리센터(PIMAC) 등재본](https://pimac.kdi.re.kr/study/study_view.jsp?pub_no=17490&pageNo=5&classcd=F2)
- **집행 실패 실증**: 목포시의 경우 2023년 173억 원은 전액 집행됐으나, **2024년 182억 원 중 약 54억 원(29.5%)이 불용**
  → [파이낸스투데이, "조옥현 도의원, 목포 관광거점도시 육성사업 불용·이월 문제 지적"](https://www.fntoday.co.kr/news/articleView.html?idxno=353865)

  → [문체부 입찰공고, 「2024년 관광거점도시 육성사업 컨설팅 용역」](https://mcst.go.kr/kor/s_notice/notice/bidView.jsp?pSeq=12960)

> **→ 문제 정의⑨** : 1,277억 원짜리 사업의 성과지표가 **'공정률'** 이다.
> 사전에는 KDI가 "수요 근거가 부족하다"고 지적했고, 사후에는 "돈을 다 썼는가"만 측정한다.
> **사전 수요 예측도, 사후 소비 검증도 없는 구간이 그대로 남아 있다.** ← 우리가 채울 자리

# 2. 논문·연구보고서에서 나온 구조적 문제

## 2-1. ★ 「법정 관광사업체」의 함정 — 아이디어 5의 결정적 근거

**한국문화관광연구원, 「지역 관광산업 생태계 진단과 정책 방향」 (2023.12.29)**
김윤영·정광민·전효재·김재호·김상혁
→ [보고서 원문](https://www.kcti.re.kr/web/board/boardContentsView.do?link_g_topmenu_id=15f51238586a425981abe0b5f685d43a&link_g_submenu_id=0382ccddbde44a91bd57a705ed56aade&link_g_homepage=F&board_id=2&contents_id=eb89c5b97f6945759caf25338e613551)

핵심 진단:
1. **정책–현장 괴리** : 실제 관광서비스 사업체 대부분이 **「관광진흥법」상 관광업종에 해당하지 않는데**, 지자체는 정책 대상을 법정 관광업종으로 한정하려는 경향이 있음
2. 정책이 여전히 **'전통적 관광자원 개발 중심'** 에 머물러 있어 관광자원–관광산업의 균형 발전으로 전환 필요
3. 지역 관광 소비 행태 변화와 관광객의 다양한 활동 요구에 대응하는 정책이 미흡

> **→ 문제 정의⑫ (아이디어 5의 한 줄 문제)** :
> **관광객이 실제로 돈을 쓰는 곳(카페·식당·소매점·미용실)은 법적으로 '관광사업체'가 아니다.**
> 그래서 관광 정책도, 관광 통계도, 관광 예산도 그들에게 닿지 않는다.
> **관광 소비의 대부분이 제도적 사각지대에 있다.**
> ← 데이터랩의 카드 소비 데이터는 **업종 구분 없이** 잡히므로, 우리가 이 사각지대를 처음으로 가시화할 수 있음

# 3. 그래서 우리가 무엇을 하는가 — 공모전 의도에 맞춘 솔루션

공모 주제는 **"데이터를 활용한 성과 창출 사례"** 입니다.
위 분석의 결론은 **"성과 자체가 잘못 정의되어 있다"** 이므로, 우리 제안은 자연스럽게 **성과 창출 사례 = 성과 정의의 교체**가 됩니다.

## 3-1. 제안 이름 (안)
> ## 「관광 KPI 전환 프로젝트 — 관람객 수에서 지역 소비 전환액으로」
> 부제: 데이터랩으로 만드는 축제·상권 성과지표 대안 체계

## 3-2. 대체 성과지표 5종 (전부 데이터랩 기본 데이터로 산출 가능)

| # | 지표 | 대체 대상 (현행 KPI) | 산출 데이터 |
|---|---|---|---|
| 1 | **소비 전환액 (₩/인)** | 문화관광축제 평균 관람객 수 | 카드 소비 ÷ 유동인구 |
| 2 | **상권 확산율** — 축제장 반경 밖 상권 소비 비중 | 없음 (신설) | 행정동별 카드 소비 |
| 3 | **체류 전환율** — 당일 대비 숙박 전환 비율 | 없음 (신설) | 이동통신 체류시간 |
| 4 | **가격 이상 지수** — 업종 평균 결제단가 급등 탐지 | 바가지요금 현장점검(인력) | 업종별 건당 결제액 |
| 5 | **상권 기회지수** — 수요 대비 업종 공급 결손 | 공정률(%) | 유동·체류·소비 3종 결합 |

## 3-3. ★ 심사에서 승부를 볼 실증 방법

**「2026~2027 문화관광축제 27개」를 대상으로 두 개의 순위표를 만든다.**

- **A안: 현행 KPI 순위** — 평균 관람객 수 기준
- **B안: 우리 KPI 순위** — 1인당 소비 전환액 × 상권 확산율 기준

→ **순위가 뒤집히는 축제를 찾아낸다.**
→ *"관람객 수 상위권 축제가 소비 전환 하위권"* 이라는 결과가 하나라도 나오면, 그것 자체로 **현행 KPI가 틀렸다는 결정적 증거**입니다.
→ 반대로 순위가 뒤집히지 않으면 → "현행 KPI도 유효하다"는 결론이 되어, 그것도 정책적으로 의미 있는 발견입니다. **어느 쪽이 나와도 발표가 성립**하는 안전한 설계.

## 3-4. 우리가 실제로 해결하는 것 (심사위원 질문 대비)

| 질문 | 답 |
|---|---|
| "지자체가 왜 이걸 쓰나?" | 문체부 KPI가 관람객 수라 **소비 실적을 증명할 도구가 지금 없음**. 예산 심의·의회 행정사무감사에서 방어 자료가 필요함 |
| "정부가 왜 받아들이나?" | 문체부가 이미 「관광기금 사업 및 재원적정성 평가 기초연구」로 **성과지표 타당성을 스스로 검토 중** |
| "왜 데이터랩이어야 하나?" | 소상공인 데이터에는 관광객이 없고, 관광 데이터에는 상권이 없음. **두 축을 동시에 가진 유일한 플랫폼이 데이터랩** |
| "수익모델은?" | ①지자체 축제 예산 적정성 리포트(B2G) ②프랜차이즈 출점 컨설팅(B2B) ③축제 스폰서·숙박업 사전 수요 리포트(B2B) |
| "작년 대상작과 뭐가 다른가?" | 강진 반값여행은 **한 지역의 사례**. 우리는 **전국에 적용되는 지표 체계**. 강진 사례를 검증하는 잣대도 우리 지표가 됨 |

# 4. 방어 포인트 / 주의

1. **문체부 성과관리 전략계획은 2024.4월판**입니다. 발표 전 [정부업무평가포털](https://www.evaluation.go.kr/)에서 최신판(2025·2026 시행계획)을 확인해, 축제 KPI가 바뀌었는지 반드시 재확인하세요. **바뀌었다면 "정부도 문제를 인식했다"는 근거로 쓰면 되고, 안 바뀌었다면 문제가 그대로 살아 있는 것**이라 어느 쪽이든 논리는 유지됩니다.
2. PDF 표 추출 과정에서 일부 수치의 열 정렬이 흐트러졌습니다. **발표에 인용할 숫자는 원문 PDF에서 눈으로 재확인**하세요. 특히 '관광/여행 서비스업 생산지수'의 '22년(69.2) → '23년(280.4) 급등은 기준연도 변경 가능성이 있어 그대로 쓰면 위험합니다.
3. 관광두레 81% 수치는 2024년 8월 기준입니다. 이후 전수조사 결과가 공개됐는지 확인하고, 없으면 **"2025년에도 신규 45개소를 선정하면서 전수조사 결과는 공개되지 않았다"** 로 서술하는 게 안전합니다.
4. 정부 사업을 비판하는 발표이므로, **"실패했다"보다 "지표가 목적을 따라가지 못했다"** 는 프레이밍을 쓰세요. 주최가 문체부·한국관광공사입니다.
