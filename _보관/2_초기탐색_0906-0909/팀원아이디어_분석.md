# 예린 ① 안동 디지털 관광주민증 2.0

## 무엇을 했나

**대상지: 경북 안동** (전국 89개 인구감소지역 중 하나, 2015~2020 인구 9,790명 감소)

발굴한 수치가 다층적입니다.

| 층위 | 수치 |
|---|---|
| 전국 | 발급 100만 명 돌파 (양적 성공) |
| 구례 | 발급 8만 8,440건 = **인구(2만 3,941명)의 3.7배**, 그런데 가맹점 24곳뿐 |
| 평창 | 발급 대비 이용률 10% (3만 4,605 / 34만 4,180) — 조사 대상 중 최고 |
| **안동** | **실사용률 6.7%** (발급 25만 7,198 / 이용 1만 7,322, 2026.7.5) — 경북 7개 시군 중 **1위인데도** |
| 지점 편중 | 하회마을 6,929건 + 도산서원 3,222건 = **전체 이용의 절반 이상** |
| 연휴 실측 | 하회마을 1만 5,009명 vs 인근 병산서원 **2,773명** |
| 주민 인식 | 안동시 사회조사 관광객 유치 방안 1순위 '볼거리 확충' **59.7%** (2위 숙박 11.0%의 5배), 29세 이하 65.5% |

## 강점

1. **문제 발굴 밀도가 팀 내 최고.** 전국 → 경북 → 안동 → 지점별로 층이 내려가면서 수치가 계속 나옵니다.
2. **"발급은 되는데 안 쓴다"**는 격차가 선명합니다. 6.7%는 그 자체로 강력한 숫자입니다.
3. 한일 정상회담(2026.5) 개최지, 문체부 '한국의 소도시 30선' 포함 → **국가급 홍보와 실사용률 6.7%의 대비**가 아이러니로 잘 작동합니다.
4. 처방이 *"새 앱·AI 만들지 말고 기존 QR 인프라 그대로 쓰면서 혜택 조합만 바꾼다"* — 현실적이고 저비용.
5. 출처 표기가 정확합니다(매체·제목·날짜·URL).

## 약점 / 리스크

### ★ 1. 2023년 공공부문 **대상작**과 같은 사업입니다

충북 옥천군청 「데이터랩 분석으로 디지털 관광주민증 사업의 활성화 전략을 마련하다」가 **2023 대상**입니다. 같은 대회, 같은 사업.

**다만 각도는 다릅니다.**
- 옥천 = 지자체가 **자기 사업을 활성화한 실행 사례**
- 예린님 = **실사용률 6.7%라는 실패를 데이터로 진단하고 동선을 재설계**

→ **이 차이를 발표에서 먼저 명시해야 합니다.** *"2023년 대상작이 이 사업의 가능성을 보여줬다면, 저희는 3년 뒤 실사용률 6.7%라는 결과를 진단합니다"* 로 열면 오히려 계승 구조가 됩니다. 말하지 않으면 재탕으로 보입니다.

### 2. 성과 창출 장치가 부족합니다

"테마별 릴레이 세트를 설계한다"는 **제안**입니다. 실제로 운영해야 성과가 나옵니다.
현재 성과 장치는 설문(100~200명) 하나뿐입니다.

**보강안**
- 안동시 문화관광과·가맹점에 분석 결과를 보내 **회신 확보** → "○곳이 검토 의사 회신"
- 릴레이 세트를 실제 QR로 만들어 **소규모 테스트** (10월 탈춤페스티벌 시즌)
- 가맹점 인터뷰로 "왜 참여를 안 하는가" 1차 데이터 확보

### 3. '릴레이 유도율(가정치)'이 자의적입니다

4단계 시뮬레이션이 `방문자 수 × 릴레이 유도율(가정치) × 1인당 추가소비액` 인데, **가정치가 근거 없으면 결과 전체가 무너집니다.**
→ 설문에서 *"이런 쿠폰이 있었다면 다음 장소로 이동했겠습니까"* 를 실측해 가정치를 대체해야 합니다.

### 4. 본인이 이미 짚은 난점

*"소상공인은 할인 강요가 아니라 데이터·홍보·매칭지원 세 가지로 유인해야됨(\*이게어려울듯)"*
→ 정확한 인식입니다. 이 부분이 발표에서 가장 많이 질문받을 지점입니다.

# 예린 ② 영월 로컬 F&B 가변형 팝업 공유주방

## 무엇을 했나

**대상지: 강원 영월** (인구감소지역, 덕포리가 2025 중기부 '동네상권발전소'·'지역상권활력지원사업' 대상지)

데이터랩 지역관광진단(2024.08~2025.07)을 실제로 돌려서 뽑았습니다.

| 지표 | 값 |
|---|---|
| 목적지 검색량 | **+36.3%** |
| 외지인 방문자 유입 | +9.3% |
| 숙박방문자 비율 | +5.1% |
| **외지인 체류시간** | **−7.7%** |
| 내비 검색 유형 | 음식 22.8 / 숙박 20.3 / 역사 20.2 |
| 거주지 | 강원 25.4 / 경기 25.1 / 충북 15.5 / 서울 12.9 |
| 연령 | 50~69세 우세 (남 50대 13.8%, 60대 13.2%) |
| 거리대 | 30~70km 33.52% / 140~190km 32.68% |
| 소분류 집중 | 유적지 **89.3%**, 농어촌 체험 **95.7%** |
| 유출 | 제천·정선·원주로 체류·소비 분산 |

## 강점

1. ★ **"검색량 +36.3% ↔ 체류시간 −7.7%"** — 이 격차 하나가 아이디어 전체를 지탱합니다. **수상작들이 쓰는 문법(숫자 두 개의 격차)에 완벽히 맞습니다.**
2. 데이터랩 지역관광진단을 **직접 돌려서** 뽑은 수치라 데이터 활용도 30점에 유리합니다.
3. 요일(주중/주말) × 연령(5060/2030) 세그먼트 설계가 구체적입니다.
4. 농가 직거래 + 청년 창업 테스트베드 → **지역 상생·ESG 서사**가 자연스럽게 붙습니다.
5. 중기부 상권 사업 대상지라는 **정책 훅**이 이미 있습니다.

## 약점 / 리스크

### ★ 1. 결론이 '공간 조성'으로 흘러갑니다

공유주방을 **짓는** 사업은 예산이 크고, 데이터 분석의 결론이라기보다 **사업계획서**로 읽힙니다.
심사에서 *"그래서 데이터로 무엇을 밝혔습니까?"* 라는 질문에 약해집니다.

→ **"공유주방을 짓자"가 아니라 "언제 누구에게 무엇을 팔아야 하는지를 데이터가 알려준다"** 로 무게중심을 옮기는 게 안전합니다. 공간은 수단이지 결론이 아닙니다.

### 2. 메뉴 라인업이 지나치게 상세합니다

곤드레·어수리 솥밥, 다래 크림치즈 타르트, 붉은메밀 한우 파스타… **데이터 대회인데 F&B 기획서로 읽힐 위험**이 있습니다. 예시 1~2개로 줄이고 데이터 분석 비중을 늘리는 편이 낫습니다.

### 3. 핵심 논거 하나가 아직 미검증입니다

*"③ 요일별 수요 미스매치 대응… **\*이 내용은 데이터적 확인이 필요함**"*
→ **주중/주말 가변 운영이 이 아이디어의 핵심인데 그 근거가 아직 없습니다.** 여기가 뚫리면 아이디어가 반으로 줄어듭니다. 최우선으로 확인해야 합니다.

### 4. 성과 창출

공유주방을 실제로 열 수 없으므로 시뮬레이션에 의존합니다.
→ **덕포리 상인회·서부시장 상인 대상 설문**과 **영월군 상권 담당 부서 회신**이 현실적 대안입니다.

# 현표 ③ 지방 소도시 DRT 관광셔틀 노선 최적화

## 무엇을 했나

**자료 조사의 깊이가 팀 내 최고입니다.**

- **법·제도**: 여객자동차운수사업법 3조, 국토부 「DRT 도입·운영 가이드라인」(2025.12.30), 국회 입법예고(2026.5), 한국교통연구원, 서울연구원
- **문제 발굴 4개**
  - 지역 편중: 서울 77.3% / 부산 16.4% / 제주 10.5%, 나머지 광역은 2019년 대비 하락 (나라살림)
  - 체류일수 2019년 대비 **+0.085일** 정체
  - 광주 DRT(2023.7~12) **5개월 만에 조기 종료** — 홍보 부족·긴 대기시간·부적절한 노선 설계
  - 대구 DRT 수익성 논란 → 감사청구
- **성공/실패 대비**
  - 부산 기장 타바라: 대기시간 **13.7분 → 6.9분**, 데이터 기반 시뮬레이션으로 노선 설계
  - 충북·충남 초광역 DRT: 문체부 1호 선도지구, **국비 25억+지방비 25억**, 누적 5천 명 이상
  - 경북 초광역 DRT: 2026 선정 2호, 대구공항·동대구역 도착 외국인을 안동·경주·포항으로 분산
- **해외 사례**: 일본 하쿠바무라 후레AI고(앱 등록 3,939명 중 **외국인 2,875명**, 누적 승차 12,000명 — 목표 5,000명 초과, **만족도 91%, 합승률 73.2%**), 고토히라 모비, 이즈 Izuko
- 논문 3편, 재방문율 54.7%

## 강점

1. ★ **"성패를 가른 건 예산 규모가 아니라 노선 설계의 데이터 근거 유무"** — 가설이 명확하고, 광주(실패) vs 기장(성공) 대비로 증명 구조가 서 있습니다.
2. **정책 타이밍이 완벽합니다.** 문체부 '초광역형 관광교통 혁신 선도지구' 1·2호가 지금 진행 중이고 국비가 투입되고 있습니다.
3. 해외 사례에 성과 수치가 다 있어 **벤치마크 기준선**이 확보돼 있습니다.
4. 역대 수상작 중 DRT·2차 교통 주제 **0건**.

## 약점 / 리스크

### ★ 1. 대상지가 아직 정해지지 않았습니다

군산이 후보로 언급됐지만 확정되지 않았습니다. **예린님은 안동·영월로 좁혔는데 여기만 비어 있습니다.**
대상지가 없으면 데이터 분석을 시작할 수 없고, 문제 발굴도 일반론에 머뭅니다.

### ★ 2. 산출물이 불명확합니다

자료는 방대한데 **"우리가 무엇을 만들 것인가"**가 정해지지 않았습니다. 세 갈래가 섞여 있습니다.

- (가) 신규 노선을 제안하는가?
- (나) 최적 정류장 입지를 뽑는가?
- (다) 기존 DRT를 평가하는가?

→ **(다)가 가장 안전합니다.** 광주·대구·기장·충북충남 초광역 DRT의 **사후 성과를 데이터로 비교**하면, 대상지 없이도 분석이 성립하고 "데이터 근거 유무가 성패를 갈랐다"는 가설을 **직접 검증**할 수 있습니다. 그 위에 다음 선정지 제안을 얹으면 됩니다.

### 3. 데이터 해상도 리스크

노선·정류장 단위 최적화를 하려면 OD(출발-도착) 데이터가 필요한데, **데이터랩은 시군구 단위**입니다. 정류장 설계까지는 못 갑니다.
→ 내비게이션 목적지 검색 데이터로 대체하되, 한계를 먼저 밝혀야 합니다.

### 4. 성과 창출

노선을 실제로 운행할 수 없습니다. → **기존 DRT 운영 지자체에 평가 결과를 보내 회신 확보**가 현실적입니다.

# 현표 ④ 안심귀가 정책의 범죄예방 효과 분석

## 무엇을 했나

- 안심헬프미: 만족도 **73.2%**, 두려움 감소 응답 **56%**
- 핵심 통찰: **"범죄 두려움 감소 ≠ 범죄 발생 감소"**
  → 서울시 공식 성과지표가 범죄율이 아니라 **신고·출동 실적과 체감안전도**
  → 도입 전후 범죄발생률을 비교한 공식 효과성 평가가 확인되지 않음
- 여성안심귀갓길 연구(2026, 서울 8곳): 5대 범죄·노상범죄 감소 경향이나 **CCTV와 조명은 통계적으로 유의하지 않음**
- 나웅재 외(2024) 유성구 **100m 격자 분석**: 안심귀갓길 + 안심시설물 **동시 설치 시** 효과 최대
- 서울 5대 범죄 86,213(2023) → 80,819(2024), **−6.3%**. 그러나 **장기 감소 추세라 인과 추론 부적절** (본인이 먼저 지적)
- 대조 사례: 지하철경찰대 부축빼기 390 → 109건(**−72.1%**), 소매치기 −20.4%, 112신고 −14.9%
- CPTED 논문 3편 + 손동필(2026) 체계적 문헌고찰(국내 279편·국외 120편)

## 강점

1. ★ **방법론적 엄밀성이 팀 내 최고입니다.** *"단순 전후 비교만으로 인과관계를 추론하는 것은 적절하지 않다고 판단됨"* 을 **본인이 먼저 적었습니다.** 이 자기검증은 심사에서 큰 강점입니다.
2. **인식 vs 실제**라는 프레임이 선명합니다.
3. 대조 사례(지하철경찰대)를 제시해 *"실제 범죄를 줄인 정책은 이렇게 생겼다"* 를 보여준 구성이 좋습니다.

## 약점 / 리스크

### ★★ 1. 관광 대회인데 관광이 없습니다 — 가장 큰 문제

안심헬프미·여성안심귀갓길은 **시민 안전 정책이지 관광 정책이 아닙니다.** 데이터랩을 어디에 쓸지도 불명확합니다.
심사위원 첫 질문이 *"이게 관광과 무슨 관계입니까?"* 가 됩니다.

**→ 살리려면 관광 쪽으로 각도를 틀어야 합니다.**
- 관광지·야간관광 상권의 안전 (외국인 관광객 대상)
- 2021 수상작(서울경찰청 관광경찰대)이 **관광 빅데이터 + 경찰 빅데이터를 융합**한 전례가 있습니다
- 다만 **2025 우수상 부산 NSI(야간관광 안전지수)** 와 정면 충돌합니다

### 2. 안전 주제는 5년 중 4년 수상자가 나온 포화 영역입니다

### 3. 방향이 아직 유동적입니다
