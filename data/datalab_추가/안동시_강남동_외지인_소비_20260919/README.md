## 출처와 재현 경로

- 한국관광 데이터랩 > 빅데이터 > 신용카드 > 지역별 관광지출액
- https://datalab.visitkorea.or.kr/datalab/portal/bda/getByLocgoCnsmAmt.do
- 로그인 후 지역: **경상북도 → 안동시 → 강남동**.
- 내국인 지출액 탭에서 이용자 구분: **외지인(b)**. 탭 제목 ‘내국인 지출액’만 보고 내국인 전체라고 해석하지 않는다.
- 월간 조회: 202401~202408 및 202601~202608.
- 관광소비 추이 → 관광총소비 → 각 월의 툴팁. 표시 단위는 **천원**.
- 업종별 지출액 → 각 영역 툴팁에서 비중 확인.
- 읍면동 단위는 사이트 안내상 다운로드 기능을 지원하지 않는다. 첨부 CSV는 공식 다운로드 원본이 아니라 **로그인 화면에서 확인한 표시값을 전사한 표**다.

## 사용 범위와 주의점

1. 이 값은 **강남동 전체 소비**다. 월영교 방문자의 소비 또는 월영교 반경 내 소비로 이름을 바꾸면 안 된다. 야간 시간만의 소비도 아니다.
2. ‘외지인(b)’ 선택 상태를 확인했다. 외지인 거주지 판정의 정확한 공간단위는 이번 화면 조회에서 별도 검증하지 않았으므로, ‘안동시 밖 거주자’ 등의 상세 정의를 임의로 덧붙이지 않는다.
3. 기존 전국 읍면동 CSV `BDT_02_01_002_35_1`는 시군구 코드 없이 읍면동 이름만 있어 동명 지역 구분이 불가능하다. 특히 강남동 이름만 추출한 금액을 안동시 강남동 수치로 사용하지 않는다. 기존 파일의 touDivCd=2 조건도 이번 외지인(b)=1 조건과 다르다.
4. 과거 전국자료 탐색 보고서의 소비주체·지역축 해석은 미검증 사항이 포함되어 있으므로 이번 로그인 화면의 명시적 선택조건을 우선한다.
5. 월별 표시값 합계이며 반올림 전 원시값과는 미세한 차이가 있을 수 있다. 업종별 비중으로 세부 소비액을 역산해 실측값처럼 쓰지 않는다.
