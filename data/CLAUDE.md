- 카드 소비는 **외지인(touDivCd=1)**으로 받는다. 기본값은 내국인(3.5~4.5% 차이). `data/bdt/신용카드/..._BDT_02_01_003_35.csv`는 사실상 내국인.
- 방문 연인원 정본 = `data/bdt/이동통신/방문자수_성별연령요일시간대_교차표_BDT_01_01_006_*.csv`(D1). LN_03_01_002 월별 합은 2022년 이후 과대.
- `api_region/월별_방문자수_현지인_*.csv`는 외지인 파일 중복, `검색_중분류별_LN_03_01_065.csv`는 무효. BDT_01_01_006_1의 '숙박자수' 열은 쓰지 않음.
- 기준연도 섞지 않기(방문 2020 + 소비 2022 같은 조합 금지). 2020은 코로나 기저라 체류·방문 비교에 쓰지 않음.
- 데이터랩 대량 재수집 금지(접속 차단 이력). 필요한 것만 간격 두고. pandas는 `.venv_pdf/bin/python`.
- **원격(클라우드)에서 작업할 때**: 깃 저장소에는 가상환경이 없고, 100MB 넘는 원자료 10개(이동통신 교차표 2018~2026, 시도별 외지인 지출 대용량)는 `.csv.gz`로만 있다. 처음 한 번 `pip install -r requirements.txt` → `bash scripts/원자료_복원.sh` 후 `python3`로 실행. API 키(TourAPI 등)는 저장소에 없음 — 환경 변수로만. 로컬 전용 경로(`~/Downloads`, `~/.config`, iCloud 위키)는 원격에서 없다고 가정한다.
- **철도공사 8대도시 보고서(2022.4~6)는 별개 데이터체계다.** 방문객 수(SKT 지정 관광지 방문자)·소비(신한카드 **건수**)를 데이터랩 방문 연인원·카드소비금액과 같은 표에 올리지 않는다. 관광지 단위 구조 근거로만 쓴다.
