## 주의
- **'아니오'(미방문) 응답자도 뒤 문항에 답했다**(건너뛰기 없음). 경험 문항(Q2~Q5·Q9·Q13)은 방문자 72명 기준으로 센다.
- **의향(Q6·Q8·Q10·Q12)은 행동이 아니다.** 참여율·전환율·예상 이용자 수로 바로 쓰지 않는다.
- 방문자 중 차 없는 사람(대중교통·도보·택시) 33명(46%)은 철도공사 SKT 추정 철도+버스 유입 10.5%보다 훨씬 많다 → 전체 비율을 쓰려면 이동수단별로 나눠 보거나 가중한다.
- PDF 파싱: 긴 셀 글자가 옆 칸과 겹쳐 그려지므로 글자 그리는 순서로 셀을 끊는다. 응답시각은 형식으로 잘라낸다. 5개 행을 PDF 원문과 대조해 일치 확인.
