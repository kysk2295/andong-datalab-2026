## 4. 단계별 상세

각 단계: **궁금했던 것 → 데이터 → 방법 → 결과 → 정한 것 → 스크립트**

### 0단계. 흔한 설명부터 확인
- **궁금했던 것**: KTX-이음 개통 뒤 안동 관광이 왜 기대만큼 안 살아나나. 흔히 "관광객이 줄었다", "당일치기가 늘었다"고 한다.
- **데이터**: 데이터랩 외지인 방문자 수, 숙박 현황(무박 비중)
- **방법**: 연도별 단순 비교. 2026년 자료가 8월까지라 모든 연도를 **1~8월끼리** 비교.
- **결과**: 외지인 방문 **+5.6%**(2024 → 2026). 무박 비중 86.3% → 86.4%로 거의 그대로(2019 → 2025).
- **정한 것**: 두 설명 기각. 남는 질문은 "온 사람이 어디서, 언제 돈을 못 쓰나".
- **스크립트**: `scripts/교수브리핑_수치.py` → `보고서/교수브리핑_20260922/수치.json`

### 1단계. 안동의 진짜 문제 찾기

**1-1. 전국 146개 시·군 비교**
- **데이터**: 데이터랩 외지인 카드 소비(업종별), 외지인 방문 연인원
- **방법**: 업종별 "방문 1회당 소비"를 146곳 모두 계산해 안동 순위를 봄. 안동만 보면 전국 공통 흐름인지 알 수 없어서.
- **결과**: 방문당 **체험·문화 소비**(문화서비스 + 관광유원시설 + 기타레저) 183.5원 → 152.7원, **−16.8%**. 전국 중앙 −2.0%. 146곳 중 **22번째로 많이 줄었다**. 수준은 87위로 평범 → "낮다"가 아니라 "줄고 있다".

**1-2. 업종 분해**
- **방법**: 업종마다 "전국 중앙만큼 변했다면 얼마였을까"를 계산해 실제와의 차이를 금액으로 환산.
- **결과**: 외식·숙박은 전국보다 잘 됨. 체험·문화 하락의 약 **3분의 2는 문화서비스가 2025년 중반에 한 번에 꺾인 것**(전국 −0.7%, 안동 −33.7%). 원인은 데이터로 알 수 없어 단정하지 않는다.

**1-3. 합성통제(보조 확인)**
- **뜻**: 과거에 안동과 비슷하게 움직인 도시 10곳을 섞어 "가짜 안동"을 만들고, 진짜 안동이 더 떨어졌는지 본다.
- **데이터**: 239개 시·군 분기별 체험·문화 소비
- **결과**: 2025년 이후 다섯 분기 중 네 분기에서 안동이 더 낮음. 하락 시작 시점을 어디로 두느냐에 따라 판정이 달라져(p 0.02~0.41) **방향 확인으로만** 쓴다.

- **정한 것(문제 1)**: 사람은 오는데 **체험·문화에 쓰는 돈이 줄고 있다**.
- **스크립트**: `scripts/교수님_대시보드_데이터.py`(146곳 × 업종), `scripts/교수브리핑_수치.py`, `scripts/이어드림_사후검증_패널.py` · `_합성통제.py`

### 2단계. 왜 체험으로 안 넘어가나

**2-1. 사람 있는 곳 × 혜택 있는 곳(자료 결합)**
- **데이터**: 데이터랩 읍면동별 외지인 방문, **정보공개청구로 받은 주민증 혜택업체 27곳 주소**, 소상공인 상가정보(주소 → 행정동 변환)
- **방법**: 업체 주소를 행정동으로 바꿔 동별 방문과 나란히 놓음.
- **결과**: 방문 1위 **중구동(원도심, 12.5%)에 혜택업체 0곳**, 방문 12위 도산면(2.4%)에 6곳.

**2-2. 혜택이 실제로 어디서 쓰이나(음이항 회귀)**
- **데이터**: 관광공사 주민증 누리집의 업체별 누적 이용 건수(26곳, 2026.9.21 조회)
- **질문**: 사람 많은 동네로 혜택을 옮기면 이용이 늘까?
- **방법**: 이용 건수를 동네 방문객 수와 업종으로 설명하는 회귀. 업체별 건수 차이가 매우 커서(하회마을 11,045건, 산숲 4건) 과산포를 허용하는 음이항 모형. 9/27 검정에서 포아송은 맞지 않음을 확인(분산이 평균의 약 7,000배, Cameron-Trivedi p = 0.001).
- **결과**: 이용의 **95%가 관람지**(하회마을·도산서원·유교랜드), 체험은 0.9%(월 약 7건). 사람 많은 동네라고 더 쓰이지 않음(의미 없음). **업종이 갈랐다**: 관람지는 식당보다 약 47배.

- **정한 것(1단계 근거)**: 혜택을 원도심으로 옮기는 것만으로는 부족하다. **식사한 사람을 바로 체험으로 넘기는 장치**(영수증 QR → 체험권)가 필요하다.
- **스크립트**: `scripts/교수브리핑_수치.py`(혜택 배치), `scripts/이어드림_파라미터추정.py` A절(음이항)

- **결과**: 저녁 승차는 **18~19시 최대**(13,454명), **막차 21~22시**, 22시 이후 0명. 팀 설문에서도 당일 귀가자의 58%가 20~22시에 귀가.

### 4단계. 저녁에 원도심에서 월영교로 어떻게 가나
- **데이터**: 안동시 버스정보시스템 공개 자료(46개 노선 시간표, 정류장 3,305곳)
- **방법**: 노선별 정류장 순서를 따라 "원도심 → 월영교" 노선을 골라 시각 확인.
- **결과**: 원도심–월영교(3.2km)를 잇는 버스는 **112번 하나**, 하루 6회. 원도심 출발 막차 **18:45** → **19시 이후 0회**. 설문: 시내버스 이용자 73%가 불편.
- **정한 것(2단계 근거)**: 저녁 이동 수단(관광택시 재배치, 확대 시 셔틀).
- **스크립트**: `scripts/작업목록_1-12_보강.py` → `조사/01_시내버스_노선시간표.xlsx`, `조사/04_BIS정류장_위치.xlsx`

### 5단계. 월영교 밤에는 무엇이 없나

**5-1. 사람은 월영교에 모이나(연관규칙 역산)**
- **데이터**: 한국철도공사 8대 도시 관광 분석(2022.4~6). "A에 간 사람 중 B에도 간 비율"이 실려 있다.
- **방법**: 보고서 숫자를 거꾸로 계산해 동시 방문 비율 복원.
- **결과**: 만휴정 방문자의 54.8%, 도산서원 방문자의 54.2%가 월영교에도 간다. 그런데 월영교는 방문 점유율 15.2% 대비 **소비 건수 점유율 6.1%**. 원도심 방문자 중 저녁에 월영교로 가는 비율 약 **15~17%**(8단계 재료).

**5-2. 월영교 주변에 갈 곳이 있나(반경 분석)**
- **데이터**: 소상공인 상가정보 음식점 3,254곳 좌표, 팀 현장 확인 영업 종료 시각(`조사/16`)
- **방법**: 월영교에서 1km 안 가게의 업종·영업시간.
- **결과**: 영업 음식점 16곳 중 **21시까지 식사 3곳, 주점 0곳**(원도심 1km엔 주점 86곳). 18시 이후 체험은 문보트·황포돛배뿐. 설문: 20시 이후 편의시설 부족 53%.

**5-3. 월영야행 축제 효과(사건연구)**
- **데이터**: 강남동(월영교 소재) 월별 외지인 소비, 월영야행 개최일
- **방법**: 축제 달에 강남동 소비 비중이 늘었는지 OLS 회귀.
- **결과**: 통계적으로 **늘지 않음**(p = 0.28).

- **정한 것(3단계 근거)**: 일시적 행사보다 **상시 야간 팝업**과 원도심 연결.
- **스크립트**: `scripts/이어드림_파라미터추정.py` B·C절, `scripts/월영교_반경_음식점.py`

### 6단계. 방문객도 그렇게 느끼나(온라인 설문)
- **데이터**: 팀 구글폼 103명, 최근 3년 방문자 72명(2026.9.23~24)
- **결과**

| 설문 | 연결되는 분석 |

### 7단계. 해결책: 안동 이어드림 3단계 릴레이

| 단계 | 운영안 | 근거 단계 |
|---|---|---|
| 1단계 식음 → 체험 | 원도심 관광 식당(83곳) 영수증 QR 인증 → 체험권 | 2, 6 |
| 2단계 야간 이동 | 18:30~21:00, 원도심 → 월영교 택시·셔틀 | 3, 4 |

### 8단계. 하면 얼마나 바뀌나(기대효과)
- **어려운 점**: 해 본 곳이 없어 결과 데이터가 없다.
- **방법 1. 재료 값 추정(파라미터 추정)**

| 재료 | 출처 | 성격 |
|---|---|---|
| 참여율 | 2-2 음이항 예측, 반값여행 신청률, 하회마을 이용률 | 실측·사례 |
| 저녁 이동 비율 | 5-1 연관규칙 역산(15~17%) | 추정 |
| 체험 가격 | 체험 27개 실제 가격 | 실측 |
| 팝업 객단가 | 문화관광축제 56개 방문당 소비 | 사례 |
| 체험 결제율, 원래 썼을 돈 비율 | 데이터 없음 | **가정** |

- **방법 2. 몬테카를로**: 모르는 값을 범위 안에서 무작위로 뽑아 계산식에 넣기를 1만 번 반복 → 결과의 범위.
- **결과(확대안, 식당 83곳, 8개월, 중앙값)**: 체험 결제 약 13,700건, 방문당 체험·문화 소비 +4.0% = 격차의 **22%**. 격차의 절반을 메우려면 **참여율 5.3%** 필요(지금까지 확인된 이용률은 1% 이하).
- **민감도**: 결과를 가장 흔드는 값은 체험 가격 > 체험 결제율 > 참여율 > 반사실. 시행 첫 달에 먼저 잴 값.
- **스크립트**: `scripts/이어드림_파라미터추정.py` → `scripts/이어드림_시뮬레이션.py` → `보고서/성과도출_20260922/시뮬레이션결과.json`

### 9단계. 시행 후 효과를 어떻게 확인하나
- **문제의식**: 시행 뒤 소비가 늘어도 이어드림 덕분인지 구분해야 한다.
- **방법 1. 순차 확대(주 검증)**: 식당 83곳을 4묶음으로 나눠 여는 순서를 추첨. 매달 먼저 연 식당과 아직 안 연 식당을 같은 달끼리 비교. 검정력(진짜 효과를 잡아낼 확률)을 모의실험으로 계산 → 83곳이면 5개월 안에 +50% 효과를 **86%** 확률로 잡는다.
- **방법 2. 합성통제(보조)**: 1-3의 "가짜 안동" 비교를 시행 후에도. 도시 지표는 출렁임이 커서 효과가 **+24% 이상**이어야 판정 → 보조로만.
- 보고서 **08절 "시행 후 효과 평가 계획"**, 대시보드 「효과 평가」 화면이 이 단계다(9/27 전 이름은 "사후 검증". 통계의 "사후검정"과 헷갈려 바꿨다).
- **스크립트**: `scripts/이어드림_순차도입_검정력.py`, `scripts/이어드림_사후검증_합성통제.py`

### 10단계. 다른 지역에도 쓸 수 있나(전국 진단표)
- **데이터**: 전국 144개 시·군의 네 지표(체험·문화 소비 변화율, 평균 숙박일수, 저녁 전환율, 야간 방문 비중)
- **방법**: 지표마다 순위를 0~100 문제 점수로 바꾸고, 하위 25% 지표 조합으로 유형 분류.
- **결과**: 안동과 같은 유형(체험 소비 하락 + 짧은 숙박) **6곳**(영덕·양양·남해·울진·광명·강릉) → 확산 후보.
- **스크립트**: `scripts/전국진단표.py` → `보고서/전국진단_20260923/`

## 8. 파일을 고치는 방법

1. **문구·화면**을 바꾸려면 생성 스크립트(`서식4_작성본.py`, `교수님_통합대시보드.py`, `교수님_보고서.py`)를 고친다.
2. **숫자**를 바꾸려면 앞단 스크립트(`이어드림_파라미터추정.py` → `이어드림_시뮬레이션.py`, `이어드림_사후검증_합성통제.py`, `전국진단표.py`)를 고치고 다시 실행한다.
3. 숫자가 바뀌면 **결과물 3개를 모두 다시 만든다.**

```bash
.venv_pdf/bin/python scripts/이어드림_파라미터추정.py
.venv_pdf/bin/python scripts/이어드림_시뮬레이션.py
.venv_pdf/bin/python scripts/서식4_작성본.py
.venv_pdf/bin/python scripts/교수님_통합대시보드.py
.venv_pdf/bin/python scripts/교수님_보고서.py
```

- 파이썬은 `.venv_pdf/bin/python`을 쓴다. 원격 작업이면 `pip install -r requirements.txt` → `bash scripts/원자료_복원.sh`.
- 대시보드는 사본을 **엑셀로** 열어 PDF로 내보내 확인한다(LibreOffice로는 축 문제가 안 보임).
- 서식4는 3쪽을 넘지 않는지 확인(스크립트가 쪽수를 출력).
- 저장소는 **공개**(https://github.com/kysk2295/andong-datalab-2026)다. 푸시하면 바로 공개되니 개인정보·API 키를 넣지 않는다.
