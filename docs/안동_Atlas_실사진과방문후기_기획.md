# 안동 Atlas 실사진·거리 보기·방문 후기

2026-09-29 · 로컬 v1.4 / 배포 보류

## 이번에 반영한 화면

지도·장소 카드·여행 재생에서 **실제 모습**을 열면 동일 장소의 실제 사진, 거리 둘러보기, 후기·방문 팁을 전환한다. 여행 중 열면 재생을 멈추고, 닫은 후 사용자가 계속 여행을 선택한다. 3D 눈높이 여행과 현장 사진을 오갈 수 있지만 사진 속 길을 연속으로 걷는 기능은 아니다.

출처가 확인된 사진 5장을 장소 7개에 연결했다. 월영교 양안, 하회마을 입구와 혜택 장소는 각각 같은 장소 전경을 공유한다. 안동역은 이전 후 승강장 사진이다. 중앙찜닭·맛50년헛제사밥은 저장소에 수집되어 있던 TourAPI의 공식 제공 사진을 쓴다. 사진 아래에 출처·권리자·라이선스·촬영일을 표시하고 촬영일 미확인은 자료 갱신일과 구별한다. 현재 외관이나 영업 상태를 보장하지 않는다.

사진이 없는 곳은 빈 상태와 공식 지도 연결을 제공한다. 아직 조성되지 않은 팝업·체험 거점에는 실사진이나 방문 후기를 붙이지 않는다. 모든 선택 메뉴는 같은 색·테두리·선택 표시를 적용하고 긴 목록에 검색 기능을 제공한다.

거리 보기는 장소 좌표의 카카오맵 로드뷰로 연결한다. 앱 안의 360도 로드뷰를 켜는 연결 코드도 있으나 공개 JavaScript 키와 허용 도메인 등록이 없어 현재는 외부 연결 방식이다. 전체 여행 경로의 연속 파노라마, 최신 촬영 보장, 현장 실시간 영상은 제공하지 않는다.

## 방문 후기의 우선순위

사용자가 고른 우선순위는 **대기·가격·주차·아이 동반**이다. 별점보다 여행 의사결정에 바로 쓸 수 있는 내용을 앞에 둔다.

| 항목 | 첫 화면에 보여줄 내용 | 수집·표시 기준 | 여행과 연결할 방법 |
|---|---|---|---|
| 대기 | 방문 요일·시간대, 실제 기다린 시간, 일행 규모 | 방문자가 기록한 지난 방문 경험. 표본 수·방문일을 함께 표시. 적은 표본은 개별 기록만 제공 | 사용자가 선택한 대기 시간을 일정에 더해 귀가편 여유를 다시 계산 |
| 가격 | 메뉴, 몇 인분인지, 1인 지출, 결제일 | 공식 메뉴판과 방문자 결제를 분리. 할인 전후·인원·날짜를 기록하고 미확인은 빈 값으로 유지 | 확인된 메뉴와 인원을 선택했을 때만 여행 예산·실제 적용 가능한 혜택을 계산 |
| 주차 | 전용/공영/노상 구분, 요금, 입구까지 도보 | 주차 위치와 요금의 확인 날짜·출처, 접근 경로를 별도 확인. 자료 없음은 주차 불가가 아님 | 주차장→식당 보행 구간 추가, 귀환 지점도 고려 |
| 아이 동반 | 유아의자, 어린이 메뉴, 유모차 진입, 계단, 화장실 | 항목별 예/아니오/미확인. 최근 현장 확인과 방문자 제보를 구분 | 가족 여행 필터와 이동 부담 안내. 미확인 장소를 자동으로 제외하지 않음 |

현재 화면에는 네 항목의 틀과 확인 상태, 기존 공식 운영 시간·주소·전화·자료 날짜를 넣었다. **실제 후기 본문 수집은 0건**이며 별점·후기 수·요약을 생성하지 않았다. 카카오맵 버튼은 상호 검색으로 이어지므로 동일 주소의 장소를 사용자가 확인하도록 안내한다.

## 다음 구현 후보

1. **식당 상세를 여행 결정 화면으로 만들기**: 실제 외관 → 방문 실용 정보 → 내 도착 예상 시각 → 이용 가능한 혜택 → 코스에 넣기. 공식 운영 시간이 지난 자료이면 확인 날짜를 함께 보여주며 자동으로 영업 중이라고 단정하지 않는다.
2. **가족/차량/대중교통 필터**: 가족은 의자·유모차, 차량은 주차 위치, 대중교통은 하차 후 걷는 시간을 먼저 보여준다. 미확인 항목을 별도 묶어 선택지를 투명하게 남긴다.
3. **후기와 일정 연결**: ‘대기 시간을 내 일정에 반영’ 시 체류 시간과 귀가 여유를 갱신하고 조정 전후를 비교한다. 지난 후기 평균을 실시간 대기로 표시하지 않는다.
4. **혜택 사용 기록**: 주민증·영수증 혜택의 대상 메뉴, 인원, 기간, 중복 적용 조건을 먼저 확인한다. 방문자가 실제 적용받은 사례와 제안 시뮬레이션을 구분한다.
5. **여행 종료 후 짧은 후기**: 네 항목 중 답할 수 있는 것만 입력. 방문일과 사진 촬영 동의를 받으며 영수증 개인정보는 제거한다. 작성·신고·삭제·운영자 확인 기능까지 준비한 뒤 공개 후기를 받는다.

첫 후속 작업으로는 **식당 5~10곳의 공식 실용 정보 확인**을 권한다. 네 항목을 실제로 채운 상세 카드와 경로/귀가 연결을 검증한 후 방문자 후기 수집을 열면 된다. 위 숫자는 작업 규모 제안이며 현재 조사 완료 수가 아니다.

## 자료와 구현 경계

- 기존 TourAPI 응답을 식당 상호와 매칭해 사용했다. 다른 가게 사진이나 미니어처 이미지를 실사진으로 대체하지 않는다.
- Kakao 장소 검색 API와 지도 URL은 장소 접근 수단이다. 후기 본문을 자유롭게 재배포할 수 있는 API로 취급하지 않는다. 외부 후기 수집은 제공자 계약·허용 방식이 확인된 후 별도로 구현한다.
- 사업 기대효과의 기존 원본 계산은 유지한다. 사진 조회나 혜택 배치를 변경했다고 연간 소비 증가 수치를 임의로 올리지 않는다.
- 후속 검증 지표: 사진 열람→코스 추가 비율, 실용 정보 확인 비율, 귀가 초과를 해소한 일정 변경, 실제 확인된 혜택 사용. 시연 클릭과 실제 방문/매출을 분리해 측정한다.
- `public/data/place-media.json`은 출처 메타데이터만 로컬에 저장한다. 사진은 사용자가 해당 화면을 열 때 원 제공처에서 불러오므로 네트워크가 필요하다.

## 확인한 공식 자료

- [Kakao Maps 시작하기](https://apis.map.kakao.com/web/guide/): JavaScript 키와 웹 도메인 설정, 지도·로드뷰 URL.
- [Kakao 기본 로드뷰 예제](https://apis.map.kakao.com/web/sample/basicRoadview/): 주변 촬영 지점 탐색과 뷰어 연결.
- [한국관광공사 TourAPI](https://api.visitkorea.or.kr/): 저장소에 수집한 관광정보·사진 메타데이터의 제공처.
- [공공누리 제3유형](https://www.kogl.or.kr/info/licenseType3.do): 출처 표시와 변경 금지. 해당 사진은 자르지 않고 전체를 표시한다.
- Wikimedia Commons의 [월영교](https://commons.wikimedia.org/wiki/File:Woryeong_Bridge_Andong.JPG), [하회마을](https://commons.wikimedia.org/wiki/File:Hahoe_8784.jpg), [안동역 승강장](https://commons.wikimedia.org/wiki/File:20211114_%EC%95%88%EB%8F%99%EC%97%AD_%EC%8A%B9%EA%B0%95%EC%9E%A5.jpg): 개별 사진의 저작자·촬영일·라이선스.
