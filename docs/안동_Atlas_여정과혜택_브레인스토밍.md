# 안동 Atlas — 여정과 혜택을 연결하는 화면 구상

2026-09-28. 사용자와 논의할 기능 후보이며 확정 사업계획이나 구현 완료 기록이 아니다. 기존 이어드림의 식음→체험 / 저녁 이동 / 월영교 팝업 3단계는 유지한다. 배포는 계속 보류한다.

## 이번 대화에서 정한 범위

- 식당·체험 장소를 누르면 상세 정보가 열려야 한다.
- 안동역에서 KTX를 내린 이후 월영교까지의 여정을 보여준다.
- 사용자가 명확히 한 ‘다른 지역’은 안동 안의 하회마을·터미널·원도심 등이다. 시외 출발 도시를 이번 우선 범위에 넣지 않는다.
- 기존 혜택의 위치와 혜택 장소를 추가했을 때의 변화를 탐색한다.
- 이 문서의 추가 기능·계산 방식은 브레인스토밍 제안이다.

## 1. 장소를 누르면 여행 행동으로 연결

식당·체험·혜택·정류장을 종류별 표식과 해당 건물 강조로 표시한다. 넓은 지도에서는 묶고 확대하면 개별 장소를 보여준다. 주소 점만 확보한 경우 건물 일치를 확인하기 전까지 표식으로 표시한다.

상세 창의 내용:
- 사진, 이름, 업종, 주소, 확인된 영업시간과 휴무.
- 식당: 대표 메뉴·가격, 영수증 인증 가능 여부, 연결 가능한 체험.
- 체험: 프로그램·가격·소요시간·예약 필요 여부, 할인 전후 금액.
- 혜택: 기존 주민증 혜택 / 이어드림 제안 혜택, 조건·대상·기간·중복 적용 여부.
- 선택한 여정에서의 도보·대기·승차 시간, 다음 목적지와 연결 상태.
- ‘여정에 추가’, ‘연결 체험 보기’, ‘월영교까지 보기’.

알 수 없는 정보는 미확인으로 두고, 할인 중복을 임의로 합산하지 않는다. 선택한 여행 시각의 이용 가능 상태와 실제 현재 영업 상태를 혼동하지 않게 한다.

## 2. 출발지와 시각에 따른 관광객 여정

출발지는 안동역(KTX 하차), 터미널, 하회마을, 원도심부터 구성한다. 출발 시각과 교통수단을 선택하고, 필요하면 귀가 열차 시각을 넣는다.

예시 흐름: 안동역 → 정류장까지 걷기 → 버스 대기·승차 → 원도심 식당 → 연결 체험 → 월영교 → 팝업 → 안동역 복귀.

- 버스는 연결된 도로와 정류장을 따라 움직이고, 사람은 하차·대기·보행·장소 진입을 순서대로 보여준다.
- 같은 관광객을 따라가며 지금의 행동과 다음 행동을 설명한다.
- 출발지별로 여러 여행 그룹을 보여줄 수 있지만 화면 속 수량은 관측 인원이 아닌 시나리오 표현이다.
- 현재 교통과 제안 저녁 이동을 각각 선택할 수 있다. 제안 차량은 확정 운행 노선처럼 표시하지 않는다.
- 월영교 직행과 식음·체험 경유를 비교하고, 경유 여정이 실제 시간 안에 가능한지 계산한다.

## 3. 혜택 장소 추가와 전후 비교

‘기존 혜택 / 사업 참여 후보 / 내가 추가한 제안’을 표시한다. 기존 업소를 선택해 혜택·적용시간·참여 조건을 설정하며, 취소·초기화와 변경 전 비교를 제공한다.

변화는 두 층으로 나눈다.

| 지도와 시간표로 계산할 변화 | 행동·소비 가정을 넣어 계산할 변화 |
|---|---|
| 도보 5·10·15분 내 이용 가능한 혜택 | 해당 경로를 선택할 비율 |
| 식사 후 종료 전 도착 가능한 체험 | QR 인증·체험 결제·주민증 혜택 이용 |
| 월영교와 귀가 교통까지 이어지는 여정 | 추가 소비와 운영비 |
| 같은 혜택의 중복 배치, 비어 있는 구역 | 낮은·기준·높은 참여 조건별 결과 범위 |

혜택 점 하나를 늘렸다는 이유만으로 매출을 자동 증가시키지 않는다. 기존 지출 이동·혜택 중복·수용 인원·할인 부담을 반영할 수 있어야 한다. 공간별 행동계수가 아직 없다면 접근성 결과만 계산하고 소비 효과는 계산 준비 중으로 둔다. QR 인증과 주민증 이용 실적은 따로 센다.

## 추천하는 첫 시연

안동역을 출발지로 고름 → 식당을 눌러 정보 확인 → 체험 혜택을 여정에 추가 → 관광객의 이용과 이동을 따라감 → 월영교 팝업을 확인 → 귀가편에 맞춰 복귀 가능 여부 확인 → 기본안·확대안과 변경 전후를 비교.

구현 순서 제안은 장소 정보 연결 → 출발지별 여정과 귀가 → 혜택 편집과 접근성 비교 → 분석 모델과 예상 효과 연결이다. 화면은 기존 참고 사이트의 전체 지도와 작은 떠 있는 패널을 유지하며, 긴 정보는 선택했을 때만 펼친다.
