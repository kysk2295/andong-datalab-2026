## 2. 공통 틀 (모든 그림)

```
1. 번호 제목 (지표, 기간)                      ← 굵게 8.5pt, 카드 밖 왼쪽 위
┌─────────────────────────────────────────┐
│ 카드 제목 ⓘ [외지인]                  ··· │  ← 제목 8.5pt 굵게, ⓘ 회색 원, 태그 파랑 칩
│ (단위)                                     │  ← 단위는 축 위 왼쪽, 괄호
│  ── 격자 연회색 ──                         │
│  차트                                      │
│        ■ 범례1   ■ 범례2   --- 기준선       │  ← 범례는 카드 아래 가운데
└─────────────────────────────────────────┘
─────────────────────────────────────────────
  <한국관광 데이터랩 · 출처> 한 줄 설명            ← 캡션 띠, 가운데 8.5pt
```

- **태그**: 실측 = `외지인`·`현지인`·`실적`, 모의실험 = `예측`, 설문 = `설문 72명`, 철도공사 = `철도공사 2022` (데이터랩과 다른 체계임을 태그로 밝힌다).
- **캡션 띠**: `<출처>` + 한 줄 설명. 예측 그림에는 "시행 전 예측, 1만 번 계산의 가운데 값"을 넣는다.
- 한 PNG에 카드 1개(반쪽) 또는 2개(가로 한 줄)까지. 3개 이상은 나눈다.

### 크기

| 용도 | 너비 | 비고 |
|---|---|---|
| 서식4 가로 한 줄 (카드 2개) | 6.7인치 = 170mm | 서식4 본문 폭. **1:1로 들어가게 이 너비로 그린다** (지금 d1~d3은 7.4인치 → 다음 수정 때 맞춤) |
| 서식4·보고서 반쪽 (카드 1개) | 3.3인치 | |
| 발표 슬라이드 | 11인치 | 글자 1.4배 |
| 해상도 | 300dpi, 흰 바탕 | |

인쇄 기준 글자 최소 7pt(눈금·범례), 값 라벨 7~8pt, 카드 제목 8.5pt, 캡션 8.5pt.

## 5. 글자와 숫자

- 글꼴: 나눔고딕(`NanumGothic`). **나눔고딕에 수학 마이너스(U+2212)가 없으므로** 그림에서는 하이픈 `-`을 쓴다. (서식4 본문은 `−` 그대로)
- 단위: 원 · 억 원 · 명 · 건 · %. 축 단위는 축 위에 `(원)`. 값 라벨에는 단위를 붙이지 않고 표·타일에서만 붙인다.
- 소수: 방문당 소비 1자리(152.7), 비율 1자리(-16.8%), 억 원 2자리(1.56억), 사람·건수는 정수 + 천 단위 쉼표.
- 제목은 결론을 쓰지 않고 **무엇을 그렸는지**만 쓴다("안동시 월별 방문 1회당 체험·문화 소비"). 결론은 본문 몫이다.
- 쉬운 말. "P50" "δ" "λ" 대신 "가운데 값" "효과 크기" "저녁 이동 배수".
- 엠대시(—) 금지, 감탄·수식어 금지.

## 6. 규칙 (데이터 쪽, CLAUDE.md 4·5장에서 그림에 걸리는 것)

- 철도공사 8대 도시(2022.4~6) 숫자는 데이터랩 숫자와 **한 그림에 올리지 않는다.** 태그 `철도공사 2022`.
- 안동 값에는 늘 **전국 중앙값**을 같이 그린다("안동만 하락" 오해 방지).
- 방문당 소비라고 쓴다(1인당 ✗). 연 방문 1,172만을 그대로 쓰지 않는다.
- 설문 의향 %는 "의향"으로만. 참여율 축과 한 그림에 두지 않는다.
- 모의실험 범위는 "1만 번 계산 중 90% 범위". 신뢰구간 ✗.
- 합성통제 p값 그림에는 "판정 보조, 확정 아님"을 캡션에.
- 순위 예측은 "다른 시·군이 그대로일 때"를 캡션에.

## 8. 만드는 순서와 점검

1. A부터 만든다. 서식4에 실제로 들어갈 수 있는 건 쪽수 때문에 2~3장뿐이라, A 중에서 팀이 고른다.
2. 새 그림은 `scripts/데이터랩형_그림.py`에 함수 하나씩 추가(공통 틀 재사용). 출력 이름 `d<번호>_<내용>.png`.
3. 저장 후 **그림을 직접 열어 본다**: 글자 겹침, 카드 밖으로 나간 라벨, 기준선이 글자를 가로지르는지, 범례가 카드 폭을 넘는지.
4. 숫자는 서식4 문구와 같은지 대조(같은 JSON을 읽으므로 원칙상 같다).
5. 작업일지에 그림 이름과 쓴 데이터를 적는다.
