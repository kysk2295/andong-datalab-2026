## A5 명세 (핵심)

```
입력 1: data/external/팀원취합_정제/안동역_승하차_월별_열차종류별_long.csv (41,616행)
        축: 월 × 구분(평일/주말/공휴일) × 요일 × 시간대 × 열차종류 × 승하차
입력 2: data/bdt/이동통신/방문자수_..._BDT_01_01_006_2026.csv (외지인, 시간대)

연산
  ① 시간대별 승차 비중 P_out(t)  — 열차 범위 명시(전 열차 / KTX-이음만)
  ② 시간대별 방문자 비중 P_stay(t)
  ③ 이탈 지표 R(t) = P_out(t) / P_stay(t)   ← 체류 대비 유출 강도
  ④ R(t)가 급증하는 t* = 이탈 임계 시각
  ⑤ 역산: t* − (1단계+2단계+3단계 소요시간) = 릴레이 권장 개시 시각

출력
  · 시간대 곡선 2개 겹친 그래프 (승차 / 방문)
  · 릴레이 개시 시각표 + 단계별 마감 시각
  · 셔틀 운행 구간(시작~종료 시각, 배차 간격)

주의
  · 값은 '그 달의 해당 요일 전체 합'(일평균 아님)
  · 0은 정차 열차 없음과 구분 안 됨
  · 저녁 전환율 0.557 = 전국중앙 0.559 → "수준"이 아니라 "분포"로만 해석
```

# 2층. 추정 모델

## B1. 기대치 모델 (횡단면 OLS) — **Y 교체 필요**

기존 모델은 Y가 '현지 관광소비'였고, 그 기준 **안동 격차 +3.9%(75/122) = 부족하지 않음**으로 나온다.
주장이 체험이면 Y도 체험이어야 한다.

```
Y   log(방문당 체험·문화 소비 + 1)        ← 문화서비스+관광유원시설+기타레저, 2026 1~8월
X   log(방문 연인원)          기존 유의 (+)
    숙박객 비중               기존 유의 (+0.05/%p)
    야간 방문 비중            기존 유의 (−)
    주말 비중
    수도권 비중
    권역 더미 · 군 더미
    [신규] 문화관광축제 보유 더미
    [신규] log(관광공사 등록 관광시설 수)   ← 조사/12_관광공사_시설수.csv
                                            공급을 통제해야 '수요 격차'가 분리된다

방법  OLS + HC3 robust SE · VIF 점검(기존 산출 있음) · 5-fold CV(R², MAPE)
표본  146곳 중 X 결측 제외 (기존 122곳)
출력  ① 계수표 ② 예측 vs 실제 산점도 ③ 안동 조건대비 격차(%)와 전국 순위
      ④ 민감도: 표본·변수·연도 6조건

해석 규칙
  격차가 크면 → "조건 대비 덜 쓴다" = 개선 여지의 상한
  격차가 작으면 → 주장을 '수준'이 아니라 '변화(−16.8%)'로 유지
  ※ 어느 쪽이 나와도 서사가 성립하도록 미리 두 문장을 준비해 둔다
```

## B2. 퍼널 효과 시뮬레이션 (몬테카를로)

```
효과 = 모수 × 인지율 × p1 × p2 × p3 × 증분객단가

파라미터        하한   기준   상한   분포      태그
모수(명)        11,726,312 (고정)                실측
인지율          0.02   0.05   0.10   삼각      실측(P2 파일럿)
p1 1단계 참여   0.05   0.12   0.25   삼각      추정(주민증 19,353건 기반)
p2 2단계 전환   0.15   0.30   0.50   삼각      가정(P1 의향 × 감쇠)
p3 3단계 전환   0.10   0.20   0.35   삼각      가정
증분객단가(원)  3,000  8,000  15,000 삼각      실측+가정
감쇠계수 δ      0.3    0.5    0.7    삼각      가정 ← 의향→행동 할인

방법  1만 회 추출 → 효과 분포
출력  ① P5 / P50 / P95 구간 ② 토네이도(파라미터별 기여도)
      ③ 목표 역산: 주민증 월 888건 → 목표 ○건에 필요한 조합

금지  의향을 전환율로 그대로 곱하지 않는다(δ 필수)
      51억은 반사실적 격차이지 손실·회복액이 아니다
```

**토네이도가 곧 P1~P4 설계 근거다.** 결과를 가장 흔드는 파라미터가 현장에서 재야 할 값이다.

# 3층. 실험 설계

## C1. P1 — 할인액 무작위 배정

```
설계  0 / 1만 / 2만 / 3만 원 무작위 배정, n=150 (군당 37.5)
Y     체험 참여 의향(0~10) 또는 선택 여부(이항)
분석  일원배치 ANOVA + 선형 추세 검정, 이항이면 로지스틱

검정력 (α=0.05, 계산 완료)
  4군 ANOVA   Cohen f=0.25 → power 0.72 · f=0.28 → 0.82
  0만 vs 3만   Cohen d=0.60 → power 0.73 · d=0.70 → 0.85

→ n=150은 '중간 크기 이상'만 감지한다. 작은 차이는 못 잡는다.
→ 보고서에 이 한계를 명시하면 오히려 신뢰가 올라간다.
→ n을 늘릴 수 없으면 **4군 대신 2군(0 vs 2만)** 으로 줄여 군당 75명 확보 권장
```

## C2. P2 — QR 퍼널 (행동 측정)

```
설계  가게 2곳에 안내카드 배치 → QR 스캔 → 랜딩 → 체험 페이지 클릭
지표  노출 대비 스캔율, 스캔 대비 클릭률
용도  B2의 '인지율' 파라미터 실측값
주의  클릭률을 실제 참여율로 쓰지 않는다(B2의 δ로 할인)
```
