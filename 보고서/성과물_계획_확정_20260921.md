# 성과물 계획 — 안동 이어드림 (2026-09-21)

솔루션: 1단계 식음→체험 / 2단계 야간 이동 / 3단계 월영교 야간 팝업.
원칙: **분석 하나가 실행 값 하나를 정한다.** 기획서에 쓰인 값 중 분석이 정하지 않은 것을 남기지 않는다.

## E 계산기 구조

```
효과 = 대상 모수 × 인지율 × 1단계 참여율 × 2단계 전환율 × 3단계 전환율 × 증분 객단가
```

| 파라미터 | 값 | 태그 |
|---|---|---|
| 대상 모수 | 외지인 방문 11,726,312명 | 실측 |
| 인지율 | P2 안내카드 QR | 실측(파일럿) |
| 1단계 참여율 | 주민증 이용 19,353건 기준 | 추정 |
| 2·3단계 전환율 | P1 의향 × 감쇠계수 | 가정 |
| 증분 객단가 | 체험·문화 152.7원 → 목표 | 실측+가정 |

각 파라미터에 하한·기준·상한 3점 → 몬테카를로 1만 회 → **구간으로 제시**.
토네이도 민감도로 어느 값이 결과를 지배하는지 표시 → P1~P4에서 무엇을 재야 하는지의 근거.

기대효과의 주민증 목표치는 R1 기준선(월평균 536 → 709 → 888건)에서 역산한다.
