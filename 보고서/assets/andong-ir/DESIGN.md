# 안동 릴레이 리서치 브리프

## 목적
교수에게 조사 자료와 실행 계획을 소개하는 편집형 보고서. 첫 화면에서 실제 장소 사진과 공간 데이터 도구를 보여준다. 질문 목록은 넣지 않는다.

## 구성
사진이 포함된 프로젝트 표지 → 작동하는 GIS 대시보드 → 상세 소개·데이터·분석 → 운영안·현장 계획 → 성과물.

## 시각 기준
흰 바탕, 차콜 텍스트, 선 중심 구획. 둥근 카드와 연녹색 카드 반복을 줄인다. 본문은 IBM Plex Sans KR, 제목도 동일한 산세리프. 숫자는 IBM Plex Mono.

## 토큰
배경 #f7f7f4, 표면 #ffffff, 글자 #20272d, 보조 #667079, 선 #d9dedf, 강조 #285a71, 보조 강조 #b56936. 간격 8/12/20/28/40px.

## GIS
Leaflet 1.9.4 / OpenStreetMap. 2026-06-30 상가정보 정제본의 3,254개 음식업종 좌표. 음식·카페·주점 필터, 장소 선택, 현재 화면 점포 집계, 실제 행정동별 집계. 주요 관광지는 표시용 대표좌표. 운영권역·숙박후보·시간대 반응 차트는 명시한 가정/예시.

## 사진
월영교 Christian Bolz CC BY-SA 4.0; 하회마을 Idobi / Inkey CC BY-SA 3.0. 사진 자체는 변경하지 않으며 CSS 표시창에서 자름. 각 사진에 원문·라이선스 표기. 현장 조사 사진으로 오인시키지 않는다.

## 반응형
큰 화면에서 좌측 필터/지도/우측 분석의 3열. 1000px 이하 우측 패널 아래 이동. 600px 이하 단일열. 지도 최소높이 440px. 표는 자체 수평 스크롤.

## 검증
실제 브라우저에서 타일·사진 로드, 필터와 범위 버튼, 지도 확대/축소, 화면 집계 갱신, 계산기, 375/768/1280px 레이아웃 확인.
