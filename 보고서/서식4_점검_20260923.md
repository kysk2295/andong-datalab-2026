# 서식4 점검 — 수상작 관점 (2026-09-23)

기준: 수상작 24편 해부(`보고서/수상작_분석기법_해부_20260918.md`)의 공통 강점·약점 + 서면 심사 배점(창의 20 / 데이터 활용도 30 / 효과성·성과창출도 30 / 파급력 20).

## 1. 데이터 신뢰성 (데이터 활용도 30)

| 항목 | 상태 | 조치 |
|---|---|---|
| 데이터 결합 | 데이터랩 8종 + 타분야 7종, 모든 수치 스크립트로 재현 | 유지. 수상작 대부분은 2~4종 |
| 비교 기준 | 전국 146곳(체험·문화)·144곳(진단)·239곳(합성통제) 중앙값·순위 병기 | 유지. 237곳/144곳 기준 저녁 전환율 중앙값(0.559/0.519)을 섞지 않는다 |
| −16.8%의 구성 | 관광유원시설(결함 업종)을 빼도 −16.5%로 유지 | 유지 |
| **−16.8%의 모양** | 하락의 약 3분의 2가 문화서비스이고, 안동 문화서비스는 2025년 중반 계단식 하락(전국 −0.7% vs 안동 −33.7%, 241곳 중 25위) | **원인 단정 금지.** "혜택 배치 때문에 줄었다"로 쓰지 않고 "줄었고, 체험으로 잇는 장치가 사람이 모이는 곳에 없다"로 병렬 서술 |
| 체험·문화의 규모 | 외지인 관광소비의 약 1%, 완전 회복해도 8개월 3.6억 원 | 기대효과를 안동 전체 %만으로 쓰지 않는다(격차 기여율 + 사업 지표) |
| 철도공사 배율(0.40·0.06) | 2022.4~6 한 시점, 소비는 **건수** | 시점·건수 표기 필수. 데이터랩 금액과 같은 표에 두지 않는다 |
| 이동통신 방문 | 주민·업무 방문 섞임(안동역 승차도 주민 포함) | "관광객"이 아니라 "외지인 방문", "승차 인원"으로 |
| **월영교 1km 영업 종료(16곳)** | 팀 현장조사 기록. **조사일·요일·방법·조사자 미기재(작업 목록 13번 미해결)** | 제출 전 한 줄 보완 필수. 없으면 "팀 현장 확인(2026.9)"으로만 약하게 인용 |
| 월영교 권역 소비 | 월영교 단위 자료 없음 → 강남동 전체로 대신 | "권역(강남동)"으로 표기 |

## 2. 인과성 (효과성 30, 창의 20)

| 주장 | 근거의 성격 | 판정 |
|---|---|---|
| 방문 1위 동에 혜택 0곳 | 관찰(두 자료 대조) | 사실. 단 "그래서 소비가 줄었다"는 인과 아님 |
| 월영교 소비가 약한 건 쓸 곳·갈 방법이 없어서 | 관찰 3개가 같은 방향(배율 0.40, 주점 0, 19시 이후 0회) | 정황상 강함, 인과 미입증 |
| 월영야행 기간 강남동 소비 | 사건연구: 효과 없음(β −0.8%/일, p 0.28) | **반박 질문 대비**: "야간 행사도 소비를 못 늘렸는데 팝업은 다른가?" → 답: 행사는 연 10일, 팝업은 상시 + 원도심 연결 + 주점 공백을 채움 |
| 사업 효과 | 시행 전 예측(몬테카를로), 핵심 가정 3개(참여율·체험 결제율·반사실) | 인과 아님. 사전등록 검증(순차 확대 추첨)으로 시행 후 인과 확인 → **수상작에 없는 강점** |
| 연결(릴레이) 효과 | 저녁 체험은 문보트뿐 → 단계를 이어야만 생기는 몫 21%(확대안) | 구조적 근거 있음, 크기는 가정 의존 |
