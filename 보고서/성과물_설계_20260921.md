## A. 섭외 업소 리스트 — "어느 가게부터"

**옥천 대상작이 한 것**: 인기 관광지 순위를 그대로 쓰지 않고 **'유료 시설만' 필터 한 줄**을 걸었다.
할인이 의미를 갖는 곳이어야 정책 수단과 데이터가 맞물리기 때문이다.

| | 내용 |
|---|---|
| 입력 | 지방행정인허가 일반음식점(영업중, 좌표·면적·종사자수) · 소상공인 상가정보 3,254곳 · 주민증 혜택업체 27곳 · 팀 현장조사 영업시간 |
| 필터 | `원도심 반경 1km` ∩ `저녁 영업` ∩ `업종 = 한식·향토음식` ∩ `혜택업체 미등록` |
| 연산 | 필터 통과 업소를 **방문 밀도 × 미등록** 2축에 배치 → 1사분면부터 섭외 순번 |
| 판정 | "릴레이가 작동하려면 최소 ○곳이 필요하고, 현재 등록은 4곳뿐이다" |
| 출력 | **섭외 우선순위 리스트(순번·상호·사유)** + 필요 업소 수 |

**지금 막힌 것**: 원도심 영업시간 데이터가 없다 → 9/24 현장조사(층화표본 60곳)로 충당.
**보완**: 표본이므로 리스트는 "표본 내 확정 ○곳 + 추정 ○곳"으로 두 칸을 나눈다.

## B. 개입 시각표 — "몇 시에 무엇을"

**PM 대상작이 한 것**: PM 이용 시간대(15~21시)와 사고 시간대(16~22시)를 겹쳐 **교집합에 개입**하고,
그 시간 그 장소에서 실제로 눈에 닿는 매체(버스정보안내기·편의점 LCD)까지 내려갔다.

| | 내용 |
|---|---|
| 입력 | **안동역 시간대별 승하차 41,616행(보유)** · 시간대별 방문 분포 BDT_01_01_006 · 릴레이 단계별 소요시간(P4 실측) |
| 연산 | ① 유출 시각 분포(승차) ② 체류 시각 분포(방문) ③ 두 분포의 **교차점** = 이탈 임계 시각 ④ 역산: 그 시각에 3단계를 끝내려면 1단계를 몇 시에 시작해야 하는가 |
| 판정 | "21~22시 승차 83,283명 중 ○%가 릴레이 완주 가능 시간대에 있다" |
| 출력 | **릴레이 권장 개시 시각표** + 단계별 마감 시각 + 안내 매체 위치(안동역 대합실·원도심 안내카드) |

**금지**: 저녁 전환율 0.557 = 전국 중앙 0.559. **"안동이 저녁에 약하다"는 성립 안 함.**
쓸 수 있는 것은 **분포(언제)**이지 **수준(심하다)**이 아니다.

**24편 중 2중 키를 제대로 쓴 건 PM 한 편이고, 그게 대상을 받았다. 여기가 우리 데이터 활용도의 승부처다.**

## C. 야간 공급 공백 지도 — "어디에"

| | 내용 |
|---|---|
| 입력 | 상가정보 3,254곳 좌표 · POI 좌표 · 혜택업체 27곳 · 고택 559곳(숙박 여부 열 보유) |
| 연산 | 반경 0.5·1km 업종별 집계(재현 검증 완료) + **방문 점유율 − 소비 점유율 격차** 중첩 |
| 판정 | 방문은 많은데 공급이 0인 칸 = 부스 입지 |
| 출력 | **공백 지도 1장** — 월영교 17곳/주점 0 vs 원도심 764곳/주점 86, 둘 사이 3.2km |

**즉시 가능한 보강**: 고택 559곳 중 숙박 가능 ○곳 ÷ 주민증 연계 3곳 = **3단계 공급 커버리지**.
현재 분자(3곳)만 있고 **분모가 없다.** 비용 0.

⚠️ **2km 반경 값은 재현 실패 → 인용 금지.** 0.5·1km만 쓴다.

## D. 전환 단절 진단지수 — 파급력 20점

부산 NSI 방식(R6 가중합). **다른 시군이 자기 점수를 계산할 수 있어야** 파급력 점수가 된다.

| | 내용 |
|---|---|
| 입력 | 146개 시·군 공통 지표 — 방문당 체험·문화 소비 변화 / 관광지 방문↔소비 격차 / 야간 검색 명소 수 / 숙박일수 |
| 연산 | 표준화 → 가중합 → 전국 분포에서 위치 |
| 출력 | **일반화 양식(계산 시트) + 전국 146곳 점수표** |

→ "안동만의 이야기"가 아니라 **"이 진단을 어디서든 돌릴 수 있다"**가 되어야 20점이 붙는다.

## E. 효과 범위 계산기 — 옥천식 역산 + 분포

**옥천이 한 것**: 대체율 계산기로 "주민 1명 소비 = 숙박객 36명 = 당일객 76명" 역산.
24편 중 목표를 숫자로 만든 유일한 방법이다.

**우리가 더할 것**: 점추정 대신 **분포**를 낸다.

```
효과 = 대상 모수 × 인지율 × 1단계 참여율 × 2단계 전환율 × 3단계 전환율 × 증분 객단가
```

| 파라미터 | 출처 | 태그 |
|---|---|---|
| 대상 모수 | 외지인 방문 연인원 11,726,312명 | **실측** |
| 인지율 | P2 안내카드 QR 노출·클릭 | **실측(파일럿)** |
| 1단계 참여율 | 주민증 이용 건수 19,353건 ÷ 발급 | **추정** |
| 2·3단계 전환율 | P1 설문 의향 × 감쇠계수 | **가정** |
| 증분 객단가 | 방문당 체험·문화 152.7원 → 목표치 | **실측 + 가정** |

- 각 파라미터에 **하한·기준·상한** 3점을 부여하고 **몬테카를로 1만 회** → 결과를 구간으로 제시
- **토네이도 민감도**: 어느 파라미터가 결과를 지배하는지 → **그게 P1~P4에서 무엇을 재야 하는지의 근거**가 된다
- 수상작 전부가 점추정 하나만 냈다. 구간 + 민감도는 **우리만의 것**

🚫 **의향을 전환율로 그대로 곱하지 않는다.** 감쇠계수를 명시하고, 그 계수가 결과를 얼마나 흔드는지 민감도에 넣는다.
🚫 **51억은 반사실적 격차이지 손실·회복액이 아니다.**

## F. 성과측정 설계 — 효과성 30점의 핵심

**수상작 24편의 공통 약점 4개를 정면으로 받는다.**

| 수상작 약점 | 우리 대응 |
|---|---|
| 비교집단 없는 전후 비교 | **합성통제 + DiD** |
| 문제 지표 ≠ 성과 지표 | 문제를 잰 지표로 성과도 잰다(방문당 체험·문화 소비) |
| 참여자 vs 평균(선택편향) | QR 참여자 ↔ 미참여 방문객 비교 설계 |
| 의향 = 행동 | P2에서 **행동**(클릭·방문)을 잰다 |

**엔진은 이미 있다** — `scripts/안동_합성통제.py`(NNLS 가중, placebo p값), `안동_합성통제_강건성.py`(인접 시군 제외·사전기간 변경).
KTX 효과 분석용으로 만든 것을 **릴레이 시행 후 설계로 전환**한다.

| | 내용 |
|---|---|
| 처치 | 안동, 릴레이 시행월 |
| 공여군 | **디지털 관광주민증 운영 + 릴레이 미시행** 지자체 (공사 공개 목록에서 추출) |
| 결과변수 | 방문당 체험·문화 소비 / 야간 시간대 소비 / 주민증 이용 건수 |
| 추론 | placebo 검정으로 p값, 사전적합 RMSPE 비율 |
| 산출 | **사전등록서 형태** — "시행 전에 이렇게 재기로 정해둔다" |

→ 아직 시행 안 한 사업이므로 **"측정 설계"를 성과물로 낸다.** 이게 오히려 강하다.
   수상작들은 사후에 비교집단이 없어 곤란했고, 우리는 **사전에 정해두는 것**을 보여준다.

# 분석 아키텍처 — 4층

```
1층  진단      R1 순위 · R2 격차 · R3 교차표 · R4 집중률   ← 본문. 정렬·뺄셈·교차표만
2층  벤치마크  기대치 모델(OLS, CV R² 0.59)                ← 부록. "조건 대비 얼마나"
3층  효과추정  퍼널 곱 × 몬테카를로 × 토네이도              ← 성과물 E
4층  인과검증  합성통제 + DiD + placebo                     ← 성과물 F
```

**1층은 단순하게, 3·4층에서 깊게.** 수상작은 1층만 있고 3·4층이 없었다.
1층에 회귀를 끌고 오면 설명 부담만 커지고, 3·4층을 비우면 효과성 30점을 버린다.

## 2층에서 반드시 고칠 것

기존 기대치 모델의 Y는 **현지 관광소비**였고, 그 기준으로 **안동 격차는 +3.9%(75/122위) = 부족하지 않음**으로 나온다.
우리 주장이 "체험·문화"인데 모델은 "부족하지 않다"고 답하는 상태다.

→ **Y를 방문당 체험·문화 소비로 바꿔 재적합한다.** 안 하면 심사에서 자기 모델에 반격당한다.
   재적합 후 격차가 작게 나오면, 주장을 **수준이 아니라 변화**로 옮긴 현재 서사와 일관되게 쓰면 된다.
