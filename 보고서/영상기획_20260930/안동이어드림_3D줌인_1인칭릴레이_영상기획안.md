# 안동 이어드림 — 3D 줌인 · 1인칭 릴레이 체험 영상 기획안

작성일: 2026-09-30 · 전달 대상: 화면 녹화 담당자, 영상 편집자, 3D 연출 담당자

> **도시를 내려다보던 시선이 한 여행자의 눈높이가 된다. 찜닭 한 끼와 영수증 인증으로 시작한 여정이, 월영교의 빛과 물결 앞에서 끝난다.**

3D 안동 전경 → 원도심으로 줌인 → 골목의 눈높이 → 식사 → 결제·영수증 수령 → QR 인증·체험 할인권 → 하회탈 만들기 → 저녁 이동 → 월영교 산책 → 밤마당에서 차 한 잔 → 수변 야경 → 제목

사업의 3단계는 유지한다. **① 원도심 식음→체험 ② 저녁 이동 ③ 월영교 야간 팝업**이며, 촬영 컷 번호는 사업 단계와 별개다.

## 3. 가장 중요한 연결: 3D 지도에서 내 눈앞으로

### 원하는 인상

관객이 지도를 보다가 그 도시 안으로 들어간다고 느끼게 한다. 3D 화면을 단순 확대하기보다, 가까운 건물과 먼 배경의 관계가 변하는 실제 지도 카메라 이동을 우선한다.

### 현재 웹으로 촬영하는 방법

1. 지도에서 원도심과 강이 함께 보이는 사선 구도를 만든다.
2. ‘원도심 상세’와 수동 줌을 이용해 찜닭골목 방향으로 접근한다. 골목이나 건물을 알아볼 수 있는 지점에서 끝낸다.
3. 별도 촬영한 릴레이 골목의 첫 구도를 지도 마지막 구도와 비슷한 전진 방향으로 맞춘다.
4. **건물 처마·어두운 문틀이 화면을 가리는 순간** 두 녹화본을 붙인다. 가림 구도가 어렵다면 골목의 진행 방향과 화면 중심을 맞춘 짧은 컷 전환을 쓴다.
5. 첫 1인칭 장면은 느린 전진으로 시작해 ‘이미 골목 안에 들어왔다’는 인상을 준다.

현재 지도와 릴레이는 별도 장면이다. 지형이 끊김 없이 이어지는 단일 카메라 비행 기능은 확인되지 않았으므로, **기본 제작 방식은 두 장면을 편집으로 연결하는 것**이다. 진짜 연속 비행이 필요하면 별도 개발 항목으로 둔다.

큰 흰 화면, 브라우저 전환, 로딩 화면은 영상에서 제외한다. 문틀에 붙이는 컷과 소리의 연속성으로 하나의 여행처럼 느끼게 한다.

## 4. 영수증 인증을 ‘다음 체험으로 이어지는 행동’으로 보여주기

관객이 다음 네 가지를 눈으로 확인할 수 있어야 한다.

| 확인할 내용 | 반드시 확보할 화면 |
|---|---|
| 식사를 마친 사람이 영수증을 받았다 | 손에 들어오는 종이와 QR |
| 그 영수증을 직접 인증한다 | 영수증을 휴대폰 화면에 맞추는 실제 조작 |
| 인증의 결과로 혜택이 생긴다 | 인증 성공과 **10% 체험 할인권 발급** |
| 받은 혜택으로 다음 체험을 이용한다 | 공방에서 할인권 사용·적용 확인 후 붓질 시작 |

- 식사, 결제, 인증, 할인권 사용은 **같은 전체 릴레이 기록**에서 촬영한다. 메뉴·영수증·혜택 상태가 컷마다 맞아야 한다.
- 인증 성공 뒤에는 읽을 시간을 준다. 성공 표시가 뜨자마자 다음 컷으로 넘기지 않는다.
- 할인권은 전통 체험 1회에 적용되는 제안 혜택이다. 밤마당 구매 장면에 다시 할인 표시를 붙이지 않는다.
- QR 장면의 안내창은 행동을 이해하는 데 필요하므로 유지한다. 영상 자막은 안내창과 겹치지 않게 배치하거나 생략한다.
- QR을 크게 확대해 화면 전체를 채우기보다, **내 손의 영수증과 휴대폰을 함께** 보여주는 구도를 우선한다.
- 실제 서버 인증·결제처럼 오인하지 않도록 첫 인증 장면에 **‘인증·혜택 시연’**을 짧게 표시한다. 결과 화면을 임의로 합성해 성공한 것처럼 만들지 않는다.

## 5. 월영교를 가장 아름답게 보이게 하는 연출

### 5-1. 다섯 가지 촬영 포인트

| 포인트 | 화면 구성 | 관객이 느껴야 할 것 |
|---|---|---|
| 첫 전경 | 가까운 난간 또는 수목 → 중간의 목교 → 먼 정자와 숲 | 걸어 나왔더니 풍경이 열리는 감탄 |
| 다리 산책 | 바닥과 난간의 선이 정자를 향한다. 정자를 화면 정중앙 또는 1/3 지점에 둔다. | 내가 직접 건너고 있다는 몰입 |
| 물에 비친 빛 | 물결과 반사가 화면의 아래 1/3~1/2을 차지한다. | 야경의 빛이 물 위로 이어지는 아름다움 |
| 밤마당의 온기 | 따뜻한 부스 조명과 가까운 손동작, 뒤편 공간의 깊이 | 풍경 옆에 머물 이유가 생기는 느낌 |
| 마지막 대표 구도 | 월영정과 다리가 충분히 크게 보이고, 수면 반사와 하늘 여백이 함께 남는다. | 안동의 밤을 오래 기억하는 여운 |

### 5-2. 촬영 전 밝기 점검이 우선

9월 30일 기존 수변 야경 캡처에서는 정자 조명은 보이지만 **난간·숲·수면의 윤곽이 상당히 어둡다.** 최종 영상은 밤의 분위기를 유지하면서도 이 세 층이 분리되어 보여야 한다.

- 목표 색감은 **남색 하늘과 물 + 따뜻한 목재·정자 조명**이다. 이 색감은 연출 목표이며 현재 릴레이에 해당 시간대 프리셋이 있다는 뜻은 아니다.
- 첫 테스트는 가장 어두운 수변 장면 5초를 녹화해 확인한다. 암부를 소폭 올려도 윤곽이 살아나지 않으면 녹화 전 3D 환경광·야경 조명을 조정하는 작업이 필요하다.
- 정자 지붕과 기둥의 형태, 난간의 목재, 물과 강 건너 숲의 경계가 읽히는 수준을 기준으로 한다.
- 조명만 하얗게 날아가거나 화면 전체가 회색으로 뜨면 조정을 줄인다. 과도한 번짐과 안개는 다리의 형태를 흐린다.
- 월영정이 작게 보이고 검은 하늘이 대부분을 차지하는 구도는 피한다. 정자와 반사를 함께 담을 수 있는 수변 위치를 먼저 찾는다.
- 분수·문보트는 화면에 자연스럽게 들어올 때만 배경으로 활용한다. 새 볼거리로 잇달아 전환하기보다 다리와 물에 시선을 머물게 한다.

### 5-3. 1인칭 카메라 공통 규칙

- 서 있을 때 사람 눈높이를 유지한다. 약 1.6~1.7m는 연출 기준이며, 사용자가 높이를 조절할 수 없는 장면은 기존 기본값을 쓴다.
- 걷기, 고개 돌리기, 물건 조작을 한꺼번에 크게 하지 않는다. **걷는다 → 멈춘다 → 본다**의 순서를 사용한다.
- 한 번 고개를 돌릴 때는 약 20~35도를 3~5초에 걸쳐 움직이는 정도를 목표로 한다. 수동 조작으로 매끄럽지 않으면 이동량을 줄인다.
- 식당과 공방은 행동이 읽히는 가까운 구도, 월영교는 공간이 느껴지는 넓은 구도를 쓴다.
- 달리기·점프·급회전·과한 좌우 흔들림은 사용하지 않는다. 밤마당의 부스를 빠르게 훑는 동작도 줄인다.
- 월영교를 위에서 도는 항공 회전은 기본안에 넣지 않는다. 후반까지 같은 여행자의 눈높이를 유지한다.

## 6. 자막·음악·편집 기준

### 자막

- 기본 자막은 타임라인에 적힌 문구만 사용한다. 한 컷 한 문장, 최대 두 줄로 제한한다.
- 인증 성공·할인권 사용 문구는 실제 화면에서 읽히면 별도 자막을 반복하지 않는다.
- 밝은 부분 위에는 자막을 피하고, 단순한 흰 글자와 약한 그림자를 사용한다. 큰 상자나 반짝이는 장식은 추가하지 않는다.
- 마지막 제목은 풍경을 가리지 않는 여백에 둔다. 정자와 수면 반사 위에 얹지 않는다.
- 시작 또는 엔딩에 **‘3D 체험 시연 · 일부 공간·혜택·운영은 제안’**을 읽을 수 있게 표시한다. 인증·차량·팝업에는 해당 장면의 성격을 짧게 덧붙인다.

### 음악과 소리

| 구간 | 소리의 역할 |
|---|---|
| 00–15초 | 공기감 있는 도입. 골목 소리가 들어오며 도시에서 사람의 시점으로 가까워진다. |
| 15–43초 | 잔잔한 리듬 위에 식기·종이·인증음·붓질을 구분해 들려준다. 인증 성공음은 한 번만 선명하게. |
| 43–49초 | 이동 소리와 함께 음악의 다음 구간을 준비한다. |
| 49–63초 | 월영교가 펼쳐질 때 선율과 공간감이 넓어진다. 물소리와 나무 발소리를 남긴다. |
| 63–71초 | 가까운 사람 소리와 잔 소리로 밤마당의 온기를 더한다. |
| 71–90초 | 타격음을 줄이고 물소리와 긴 선율로 여운을 만든다. |

음악은 약 75~90BPM의 가벼운 현악·피아노 중심 곡을 후보로 찾는다. 국악기 음색은 과하지 않게 섞을 수 있다. 이는 선곡 방향이며 특정 음원이 확보되었다는 뜻은 아니다. 사용권이 확인된 곡을 사용한다.

현재 웹의 공간 소리는 합성 효과음이다. 촬영 전 재생 여부를 확인하고 별도 녹음하거나, 편집에서 사용권을 확보한 소리로 보완한다. 기존 효과음과 새 효과음이 겹쳐 두 번 들리지 않게 한다.

### 편집

- 골목 진입은 문틀, 식당→계산대는 시선 이동, 이동→야경은 도착 후 고개 돌리기로 연결한다.
- 시간을 줄일 때는 같은 행동의 시작과 결과를 남긴다. 식사와 공방의 반복 동작을 먼저 줄인다.
- QR 정렬·성공, 할인권 발급·사용은 정상 속도로 보여준다.
- 월영교 감상 구간에는 빠른 배속과 잦은 컷 전환을 쓰지 않는다. 최소 7초씩 풍경을 유지한다.
- 색감은 지도와 골목에서 밝게 시작해 실내의 온기를 거쳐 밤으로 진행한다. 모든 장면에 같은 어두운 색보정을 일괄 적용하지 않는다.
- 화면 구석의 메뉴가 거슬리면 기존 패널 접기와 구도 조정을 먼저 사용한다. 확대·잘라내기는 필요한 조작과 정자·반사를 가리지 않는 범위에서만 쓴다.

## 7. 촬영 담당자 실행 순서

### 접속 주소

아래는 현재 프로젝트 문서에 기록된 공개 주소다. 촬영 시작 시 화면과 기록 상태를 확인한다.

| 용도 | 주소 |
|---|---|
| 3D 지도 | https://andong-atlas-production.up.railway.app/?layout=atlas |
| 릴레이 동선 참고 지도 | https://andong-atlas-production.up.railway.app/?layout=atlas&layers=relay |
| 전체 릴레이 체험 | https://andong-atlas-production.up.railway.app/?experience=relay |
| 월영교 풍경 보충 촬영 | https://andong-atlas-production.up.railway.app/?experience=relay&visit=bridge |
| 밤마당 보충 촬영 | https://andong-atlas-production.up.railway.app/?experience=relay&visit=popup |

### 촬영 순서

1. **별도 촬영용 브라우저 프로필**을 준비한다. 기존 사용자 여정을 초기화하지 않고 전체 릴레이를 새로 시작할 수 있게 한다.
2. 영상에 쓸 화면 비율을 고정하고 브라우저 주소창을 제외한 영역을 녹화한다. 기존의 지도 전체 화면 기능을 활용할 수 있다.
3. 가장 어두운 월영교 장면부터 5초 테스트한다. 해상도보다 먼저 밝기·프레임 안정성·마우스 움직임을 확인한다.
4. 전체 릴레이로 식사→영수증→인증→공방→이동을 실제 진행한다. 진행 전후를 모두 녹화해 편집 가능한 여유를 확보한다.
5. 월영교와 밤마당의 동선을 미리 한 번 걸어본다. 수변 전망대와 월영정의 가장 좋은 구도를 정한다.
6. 월영교 첫 전경, 다리 산책, 수면 반사, 마지막 대표 구도를 각각 2~3테이크 확보한다.
7. 밤마당에서 국화차 수령·맛보기 장면을 촬영한다. 팝업 촬영 때문에 전체 릴레이의 인증 기록을 바꾸지 않는다.
8. 마지막으로 지도 도입부를 촬영한다. 이미 촬영한 골목 첫 화면에 맞춰 지도 마지막 방향을 정한다.

### 기본 조작과 녹화 설정

- 현재 문서 기준: **WASD 이동 / 마우스 드래그로 시선 이동 / E 또는 클릭으로 상호작용 / R 시점 복원**. 촬영 중 R을 누르면 시점이 튈 수 있으므로 테이크 시작 전에만 쓴다.
- 지원 브라우저에서 ‘게임 조작’으로 마우스를 고정하면 커서가 화면을 가로지르는 문제를 줄일 수 있다. 지원하지 않으면 드래그 조작을 사용한다.
- 3D 재질과 장면이 완전히 로드된 후 녹화를 시작한다. 작업 중인 메뉴, 로딩 화면, 개발 도구는 제외한다.
- ‘가볍게 보기’는 해상도와 그림자를 줄이므로 꺼진 상태부터 시험한다. 프레임이 불안정하면 화면 해상도를 먼저 낮춰 안정된 30fps를 확보한다.
- 장비가 충분하면 2560×1440 이상으로 원본을 받아 1080p로 마무리한다. 60fps 녹화는 안정적으로 유지될 때만 선택하며 필수 조건은 아니다.
- 전체 UI를 숨기는 전용 촬영 모드는 확인되지 않았다. 필요한 안내창은 유지하고, 감상 장면은 메뉴를 닫아 최대한 시야를 확보한다.

## 8. 현재 가능한 촬영과 추가 작업 구분

| 항목 | 현재 자료에서 확인한 범위 | 제작 시 처리 |
|---|---|---|
| 3D 지도 탐색·줌 | 지도, 원도심 상세, 카메라 조작이 있음 | 지도 녹화본을 사용 |
| 지도→1인칭 전환 | 장면 진입 링크가 있음. 하나의 연속 지형·카메라 경로는 아님 | 두 녹화본의 방향과 가림을 맞춰 편집 |
| 식사·영수증·QR·할인 | 직접 조작과 발급·사용 기록이 있음 | 실제 시연 순서대로 녹화 |
| 하회탈 체험 | 표면 붓질과 단계 진행이 있음 | 한 작품을 완성한 과정에서 필요한 구간 추출 |
| 월영교·수변·밤마당 | 보행·시선 이동·목적지 이동과 풍경 촬영이 있음 | 대표 구도를 찾아 수동 촬영 |
| 매끄러운 자동 카메라 경로 | 영화 촬영용 경로 저장·재생 기능은 확인되지 않음 | 기본안은 수동 이동. 같은 테이크 반복이 어렵다면 별도 카메라 경로 기능 요청 |
| UI 전체 숨김 | 패널 접기는 가능. 촬영 전용 전체 숨김은 미확인 | 기존 조작으로 우선 촬영. 필요하면 안내와 상태를 보존하는 촬영 모드 추가 요청 |
| 월영교 밝기·색감 개선 | 현재 캡처는 암부가 강함 | 짧은 후보정 테스트 후 부족하면 3D 조명 조정 요청 |

**추가 개발이 필요할 경우 우선순위:** 월영교 밝기 확보 → 감상 장면의 UI 정리 → 카메라 이동 속도·반복 경로 → 지도와 1인칭의 연속 전환.

이 문서는 영상 제작 기획이다. 위 추가 기능이 구현되었다고 가정하지 않으며, 현재 가능한 촬영과 편집만으로도 기본 90초 구성을 완성할 수 있다.

## 10. 제작자 전달용 요약

> 기존 안동 Atlas와 이어드림 웹 체험을 녹화해 90초 영상을 만듭니다. 3D 안동 지도를 사선 상공에서 내려다보다 원도심으로 가까이 들어가고, 골목에 선 여행자의 눈높이로 전환합니다. 이후 찜닭 식사, 영수증 수령, 휴대폰 QR 정렬, 10% 체험 할인권 발급·사용, 하회탈 붓질, 저녁 이동을 같은 사람의 여정으로 보여주세요. 49초부터는 월영교와 밤마당에 집중합니다. 첫 전경이 열리는 순간, 목교를 걷는 시점, 물에 비친 빛, 정자를 바라보며 멈추는 순간에 충분한 시간을 주세요. 월영교는 남색 밤과 따뜻한 조명이 어우러지되 난간·숲·수면이 어둠에 묻히지 않게 조정합니다. 큰 자막과 빠른 회전을 줄이고 손동작·발소리·물소리로 몰입을 만듭니다. 마지막은 월영교 풍경 위에 ‘안동 이어드림 — 한 끼에서, 안동의 밤까지.’를 남깁니다. 지도와 1인칭은 별도 녹화본을 자연스럽게 연결하고, 인증·혜택·연결차량·팝업은 시연과 제안임을 표시합니다.
