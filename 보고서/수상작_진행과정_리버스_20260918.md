# 수상작은 어떤 순서로 일했나 — 진행과정 리버스 분석 (2026-09-18)

근거: 데이터랩 우수 활용사례 인터뷰 24편(요약 정본 `보고서/수상작_문제해결_분석_20260916.md`), NSI 성과물 해부(`부산_야간관광_NSI_성과물_분석.md`).
앞선 두 보고서가 **무엇을 문제로 잡고 무엇으로 풀었나**를 봤다면, 이 문서는 **어떤 순서로, 어디서 데이터를 구해, 어디서 멈췄나**를 복원한다.
인터뷰는 사후 서술이라 실제 순서를 미화했을 수 있다. 아래는 결과물에서 거꾸로 추론한 것이고, 추론 표시(推)를 붙였다.

---

## 1. 24편에 공통으로 보이는 6단계

```
A 계기(정책·민원·밈·사고)  →  B 데이터랩 기본메뉴로 현황 1장
→ C 외부·자체 데이터 1~2종 결합(여기서 작품이 갈림)
→ D 어긋난 두 숫자를 한 경로/한 지도로 복원
→ E 운영 변수로 처방(구축 아님)  →  F 실행 또는 사전검증 → 성과 서술
```

갈리는 지점은 **C와 F 딱 둘**이다. B까지는 24편이 거의 똑같다(방문자 추이·인기 관광지·검색 순위·성연령·체류시간). 데이터랩 메뉴만으로 끝난 작품은 전부 요약표 행(아래쪽 상)이고, C에서 남의 데이터를 붙인 작품이 대상·최우수를 받았다.

| 결합한 외부 데이터 | 작품 | 상 |
|---|---|---|
| TAAS 사고통계 + 공유PM 이용로그 | 관광지 PM 안전 | 2024 대상 |
| 자체 빅데이터 플랫폼(유동인구·카드) + 상품권·쇼핑몰 매출 | 강진 반값여행 | 2025 대상 |
| 범죄통계 + CCTV + 교통접근성 | 부산 NSI | 2025 우수 |
| 112 신고 | 서울 관광경찰대 | 2021 |
| 연안 사고 이력 | 평택해경 | 2022 우수 |
| 렌터카 위치 | 제주 | 2021 |
| 진료과목 수요·국가별 선호·OTA 채널 | 인천 의료웰니스 | 2025 최우수 |
| 자체 설문 | 김포 5味로드, KAIST 대전 | 우수 |
| 없음(데이터랩만) | 소사탕·연구개발특구·설악·구례 등 | 우수/기타 |

→ **읽는 법: 데이터랩은 문제를 여는 도구였지, 푸는 도구가 아니었다.** 처방의 근거는 대부분 바깥에서 왔다.

## 2. 데이터를 "찾은" 방법 — 세 갈래

### (가) 정책이 먼저, 데이터는 근거 조달 (공공 수상작 대부분)
강진·옥천·파주·평택해경·PM. 순서(推): 해야 할 사업이 이미 있음 → 데이터랩에서 **그 사업의 타이밍과 대상만** 확정.
- 강진: 반값여행이 결정된 뒤 3년치 월·성·연령을 봐서 **홍보를 3~5월·10월에 몰았다**. 데이터가 정한 건 사업이 아니라 달력이다.
- 옥천: 혜택업소를 넣어야 함 → 인기 관광지 중 **유료** 시설부터, 맛집 순위대로 섭외. 데이터가 정한 건 섭외 순번이다.
- 함의: 이들은 "문제 발굴"에 시간을 안 썼다. 우리처럼 145개 시·군을 스크리닝한 흔적이 공공 수상작엔 없다.

### (나) 데이터가 먼저, 문제를 발굴 (민간·학생 수상작)
KAIST 대전, 부산 NSI, 성균관대 2편, 아시아경제. 순서(推): 데이터랩 공개 지표 전수 → 군집/순위로 이상치 → 그 이상치를 문제로 선언.
- KAIST: 내비 검색 좌표에 K-Means·DBSCAN → **갑천 밀집**이라는 이상치를 먼저 찾고, 거기에 야간·무박 서사를 붙였다.
- 성균관대: 86개/전국 축제를 방문객÷예산으로 성공·실패 군집 → 변수 중요도.
- 아시아경제: '노잼 도시' 밈이라는 **비데이터 계기**로 시작해 5년치 축제 비교로 검증.
- 함의: 우리 9/16~17 전국 스크리닝·기대치 모델은 (나) 계열의 정석이고, 학생팀이 이기는 경로도 여기다.

### (다) 규정·제약을 뒤져 길을 냄 (드묾, 그러나 인상적)
윤돌섬: 절대보전 무인도서 **출입금지 조항 안의 예외(보호조치 목적 출입)**를 찾아 정화활동을 프로그램 필수요소로 넣었다. 데이터가 아니라 법령을 읽어서 만든 실행 가능성이다.

## 3. 실제로 쓴 데이터랩 메뉴 (빈도순, 推)

1. **인기 관광지 / 관광지 순위** — 옥천·윤돌섬·설악·구례·제주·소사탕. 가장 많이 쓰였고, 거의 항상 **섭외·배치의 우선순위**로 쓰였다.
2. **내비게이션 검색** — 파주·제주·KAIST·김포·인천 9경. 좌표가 있어서 군집·경로 복원에 유일하게 쓸 수 있는 데이터.
3. **방문자 수·성연령·거주지** — 전편 공통. 파주의 "수도권 92.3%"처럼 **처방의 대상 범위**를 정할 때.
4. **요일·시간대 집중률** — 파주(주말 14–18시), PM(15–21시). 개입 시각을 정한다.
5. **체류시간** — 김포·인천 9경·다움. 다만 성과 지표로 쓰면 약점이 됐다(2절).
6. **관광소비(카드)·업종 비중** — 김포·KAIST(축제 숙박 소비 비율)·아시아경제.
7. **인구감소 관광대체율 계산기** — 옥천·커뮤니케이션 다움. **목표치를 숫자로 만든 유일한 도구**이고 둘 다 대상을 받았다.

우리가 쓰고 있는데 수상작엔 거의 안 보이는 것: **전국 146개 시군 동시 비교**, **회귀 기대치 모델**. 반대로 수상작에 있고 우리에게 없는 것: **좌표 기반 내비 군집**, **관광대체율 계산기 목표설정**.

## 4. 어디서 멈췄나 (F단계) — 상과의 관계

| 멈춘 지점 | 작품 | 상 |
|---|---|---|
| 실행 + 회계 가능한 매출·발급 실적 | 강진, 옥천, 인천 의료웰니스 | 대상·최우수 |
| 실행 + 활동량만 | PM(교육 인원), 윤돌섬(참여자) | 대상·우수 |
| 시범 운영 | 김포(4,500명) | 우수 |
| 설문 의향만 | KAIST 대전(52.6%) | 우수 |
| 추정치만 | 부산 NSI(체류 +15% 등) | 우수 |
| 구축 예정 상태 | 우도 | 최우수 |
| 서비스·논문 구현만 | 제주, 제천, DScover | 수상 |

→ **실행 실적이 없어도 최우수까지 간다.** 우도는 하드웨어가 아직 없었고, NSI는 전부 추정이었다. 대신 실행이 없는 작품은 예외 없이 **설계물(지수·매트릭스·모델)이 완성품 수준**이었다. 학생팀에게 요구된 건 실적이 아니라 **끝까지 만들어진 산출물 한 덩어리**다.

## 5. 우리 진행과 대조

| 단계 | 수상작 전형 | 우리 현재 |
|---|---|---|
| A 계기 | 정책·사고·밈 | 대회 참가 자체 → 계기 서사가 약하다 |
| B 데이터랩 현황 | 1~2주, 1장 | 과다 수행(9/6~9/17). 전국 재계산·모델까지 감 |
| C 외부 결합 | 여기서 상이 갈림 | **안동역 승하차뿐**. 정보공개청구 R1~R4 미발송 |
| D 경로 복원 | 파주식 한 경로 | 미완. "역 도착→저녁 단절"을 아직 한 장으로 못 그림 |
| E 운영 처방 | 구축 아님 | 부합(릴레이·구축비 최소화) |
| F 검증 | 실행/시범/설문/추정 | P1~P4 설계 중. **수상작 평균보다 앞섬** |

**가장 큰 갭은 C다.** 대상·최우수 7편 중 6편이 외부 데이터를 결합했는데, 우리 결합물은 팀원이 받아온 안동역 승하차 한 종이다. 남은 12일에 현실적으로 붙일 수 있는 것: 정보공개청구 회신(R1 주민증 지점별 이용 = 옥천 사용건수의 상위 호환), 소상공인365 상권 리포트(이미 보유), 문체부 축제 현황(보유), 코레일 시간표(보유).

**두 번째 갭은 A다.** 강진은 재정자립도 8.5%, 옥천은 인구감소지역 지정, KAIST는 '노잼 도시'라는 **외부에서 이미 말해지고 있던 문장**에서 출발했다. 우리는 데이터에서 출발해 문장을 만드는 중이라 서두가 밋밋해질 위험이 있다. 지역을 최종 확정할 때 "그 지역에서 이미 공개적으로 말해지던 불만"이 있는지를 선정 기준에 한 칸 넣을 값어치가 있다.

**세 번째, B를 이미 과하게 했다.** 수상작 어느 편도 전국 회귀모델을 돌리지 않았고, 그래도 상을 받았다. 지금부터의 시간은 B가 아니라 C·D·F에 쓰는 편이 심사표(데이터 활용도 30 = 과정의 구체성·적합성, 효과성 30)에 더 직결된다.
