# 안동 이어드림 — HyperFrames 편집용 촬영 인수인계

## 요청
동봉한 실제 3D 웹 촬영 소스를 사용해 90초·16:9 홍보 시연 영상을 완성해 주세요. HyperFrames 스킬을 적용하고, `기획안.md`의 메시지와 14컷 흐름을 따릅니다. 3D 안동 지도에서 원도심으로 줌인하고, 1인칭으로 식사 → 영수증 QR 인증 → 체험 할인권 → 하회탈 → 이동 → 월영교·밤마당을 경험합니다. 마지막은 월영교의 빛과 수면 반사를 충분히 감상하게 만듭니다.

## 먼저 볼 파일
- `안동이어드림_90초_촬영연결본.mp4`: 장면 순서와 분량을 확인하는 90초 러프컷. 자막·BGM·최종 전환 효과 전 단계입니다.
- `기획안.md`: 승인된 기획, 카메라·문구·사운드·콘티.
- `cutlist.csv` 또는 `cutlist.json`: 소스 파일, 시작점, 종료점, 타임라인. 단위는 초이며 종료점은 포함하지 않습니다.
- `clips/`: 편집용 MP4. 연결본보다 긴 여유 구간이 있습니다.
- `stills/`: 실제 촬영 화면 및 구도 확인 이미지. 전체 영상을 스틸 슬라이드로 바꾸지 않습니다.

## 편집 기준
- 1920×1080, 30fps, 최종 90초. `cutlist`로 먼저 장면을 배치하고 전환을 넣을 경우 총 길이를 유지합니다.
- 0–10초는 실제 3D 지도 줌인. 10초 지점에서 별도의 1인칭 공간으로 편집 전환합니다. 두 공간이 연속 지형인 것처럼 과장하지 않습니다.
- 26–35초 QR 인증과 할인권 발급을 명확하게 보여 주세요. 할인은 다음 체험 1회 10% 제안이며 전체 여행·팝업에 반복 적용되는 혜택이 아닙니다.
- 35–43초 할인 적용 → 붓질 → 완성된 하회탈로 이어 주세요.
- 49초부터 야경. 월영교 전경·산책·수면 반사·엔딩 33초는 유지합니다. 야경에 설명 카드를 많이 덮지 않습니다.
- 79–90초는 같은 전경 소스의 연속 구간입니다. 마지막 4초에 기획안 엔딩 문구를 얹되 월영정과 반사를 가리지 않습니다.
- 식사·영수증·하회탈의 손과 행동을 보여 주고, 화면 모서리의 작은 안내는 필요한 경우만 강조합니다.
- 자막은 짧고 한국어로, 앱 UI와 겹치지 않게 배치합니다. 원본 게임 스타일과 어울리는 절제된 타이포그래피를 사용합니다.
- BGM·추가 효과음은 이용 가능한 라이선스의 소스로 선택합니다. 기존 소리는 앱이 합성한 효과음이며 실지 현장음이 아닙니다. 컷 연결 시 음량과 잔향을 조정해 주세요.

## 촬영 방식과 알려진 제한
촬영 대상은 로컬 `andong-atlas` 3D 웹 시연입니다. 실제 안동 현장 실사 촬영이나 현재 운영 중인 할인·셔틀·팝업의 증빙이 아닙니다. 최종 영상에 ‘안동 이어드림 제안 · 3D 체험 시연’임을 알아볼 수 있게 표시합니다. 화면의 가격과 할인은 시연 예시입니다.

식사, 결제, 영수증 수령, QR 정렬·인증, 할인권 발급·사용, 탈 꾸미기, 이동, 차 구매·맛보기는 앱의 실제 체험 흐름을 수행했습니다. 영상 촬영을 위해 조작 안내 등을 숨기고 카메라 경로와 야경 조명을 로컬 촬영 환경에서 조정했습니다.

| 소스 | 기록 방식 | 편집 시 참고 |
|---|---|---|
| S01·S02, S09·S10·S12·S13/S14, S11c | 실제 3D 장면을 카메라 경로에 따라 프레임별 기록, 30fps | 보간 이미지가 아닌 실제 렌더 프레임. 야경은 카메라 움직임과 수면 반사를 함께 기록 |
| S03–S08, S11a·S11b | 실시간 브라우저 영상, 원본 25fps → 편집 파일 30fps | 복잡한 장면은 고유 프레임 수가 적을 수 있음. 과도한 슬로모션 지양 |
| S06b_할인권발급_실제화면홀드 | 동일 체험에서 실제 발급된 할인권 화면의 정지 캡처를 3초 유지 | 러프컷에서 2.5초 사용. 녹화 중 일부 패널 누락을 보완한 실제 화면 인서트 |
| S07c_할인적용_실제화면홀드 | 실제 할인 적용 접수 화면의 정지 캡처를 3초 유지 | 러프컷에서 2초 사용. 동영상 클릭 장면으로 오인하지 않도록 참고 |

`S06_QR인증과_할인권.mp4` 단독으로는 발급 패널이 충분히 보이지 않으므로 반드시 S06b와 함께 사용합니다. `S07a_체험할인권_사용.mp4`보다 S07c 화면이 할인 내역을 읽기에 적합합니다. `S11b_국화차_구매와맛보기.mp4`는 여분 소스이며 러프컷은 산책 3초 + S11c 맛보기 5초를 사용합니다.

## 마감 작업
1. 기획안·연결본·cutlist를 확인하고 HyperFrames 프로젝트에 소스를 연결합니다.
2. 제목, 필요한 설명 자막, 지도→1인칭 전환, 음악과 음량을 완성합니다.
3. QR와 할인 내역의 가독성, 가격·제안 표기, 월영교 암부·하이라이트, 컷 사이 소리 단절을 확인합니다.
4. 지도 출처를 엔딩 크레딧 또는 설명란에 유지합니다: © OpenStreetMap contributors / OpenFreeMap, 행정경계 통계청 SGIS. 최종 공개 전 앱의 원본 출처·라이선스 표기와 대조합니다.
5. 최종 MP4, HyperFrames 편집 프로젝트, 사용 음원·폰트의 출처를 함께 전달합니다.
