# 안동 이어드림: 보유 데이터 기반 현장조사·수치 산출 계획

작성: 2026-09-24. 9월 26일 하루 답사, 팀원 4명을 가정한 제안이다. 실제 출발·귀가 일정에 맞춰 조정한다. 사업 집행이나 업체 참여 확약을 요구하지 않는다. 기존 보고서와 엑셀은 수정하지 않았다.

## 1. 이번에 완성할 수 있는 범위

**가능:** 현재 방문·소비 진단, 실제 이용 가능한 코스, 조사 응답자의 조건부 체류시간·지출 변화, 참여 규모별 체험 매출·공급·교통·비용 시나리오.

**이번 조사로 검증 불가:** 사업으로 인한 실제 평균 체류 증가, 실현된 구매 전환율, 인과적인 추가 매출, 신규 관광객 증가율. 기존 자료와 설문을 더 모아도 시행 후 관측을 대신하지 못한다.

사업 참가자 수 자체도 아직 알 수 없다. 우선 ‘적격 대상자 100명에게 안내할 경우’와 ‘실제 참여자 100명일 경우’를 명확히 구분해 계산한다. 식당 83곳이나 안동 전체 방문자에 설문 선택률을 바로 곱하지 않는다. 접촉·노출 규모를 확인할 수 없으면 연간 총액은 확정하지 않는다.

## 3. 답사 전: 9/24~25

### A. 공급 후보부터 걸러 코스 카드 두 장 준비

- 코스 A: 원도심 식사 후 개인 단위로 이용할 수 있는 유료 체험.
- 코스 B: 원도심에서 월영교로 이동해 이용 가능한 저녁 체험과 귀가 동선.
- 각 카드에는 실명 시설, 장소, 실제 확인 가격(1인/1팀/1척 구분), 예약 조건, 이동수단·비용, 체험 소요시간, 마지막 접수, 종료·귀가 시각을 적는다.
- 미확정 할인·셔틀은 현재 제공되는 서비스처럼 표시하지 않는다. 가정인 경우 금액과 조건을 명시한다. 시행 중인 사업이 아니라 검토 중인 제안이라고 설명한다.
- ‘이용하지 않음/기존 일정 유지’ 선택지를 반드시 둔다. 카드 제시 순서는 번갈아 바꾼다. 이 비교는 선호 탐색이며 인과효과 실험이 아니다.
- 원도심 인근 개인 체험이 확보되지 않으면 외곽 단체 체험으로 억지로 채우지 않는다. 낮 코스는 공급 미확인으로 남기고 저녁 코스만 구체적으로 조사한다.

확인 우선 후보:

1. 안동공예문화전시관: 개인 체험·정원·마지막 접수. 공식 관광 안내에 추석 전날·당일·다음날 휴관이 있으므로 9/26 방문 전 확인 필수. 휴관 시 현장 체험을 일정에 넣지 않는다.
2. 전통리조트 구름에: 비숙박객 개인 예약 가능 여부와 실제 운영 회차. 보유 목록의 가격만으로 이용 가능하다고 판단하지 않는다.
3. 월영교 문보트: 실제 요금, 1척 정원, 마지막 접수, 대기, 기상 취소, 가동 척수·회차. 3인 가격을 모든 이용객의 1인 가격으로 단순 환산하지 않는다.
4. 원도심 공방·주민증 체험 후보: 주소를 대조해 실제 동선에 들어오는 1~2곳만 우선 확인.

보유 목록에는 15명 이상 또는 30명 기준 단체 프로그램과 하회·도산권 시설이 섞여 있다. ‘체험 가격 27개’ 전체를 개인 원도심 코스의 가격 표본으로 사용하지 않는다.

### B. 외부에서 보충할 자료

- 공식 예약·운영 사이트: 현재 가격, 휴관, 개인 예약, 체험 회차. 미게시 항목만 전화 또는 현장 질문.
- 코레일 공식 조회: 실제 이용일·귀가 목적지별 출발 시간. 좌석 변경이 가능하다고 가정하지 않음.
- 안동 BIS·축제 공식 안내: 평상시 노선과 행사 셔틀·통제를 분리.
- 관광택시 운영처: 기존 장시간 상품 요금과 별개로 야간 단거리 구간의 제공 가능 여부와 참고 견적 문의. 공개 5시간 요금을 비례 나눠 단거리 견적으로 사용하지 않음.
- 팝업은 장소·운영 주체·비용이 확인되면 확장 시나리오에 포함. 확인되지 않으면 핵심 효과 계산에서 제외.

연휴에 문의가 연결되지 않으면 ‘미확인’을 유지한다. 기관 회신·신규 정보공개청구를 제출 전 필수 경로로 삼지 않는다. 문의 계획이며 아직 외부에 연락하지 않았다.

## 4. 현장조사 목표와 배치

권장 목표: 관광 목적 외지인 여행팀 60팀, 80팀은 여유가 있을 때. 여행팀당 성인 대표 1명에게 질문하고 동행 인원을 별도로 적는다. 표본 수는 하루 실행 목표이지 대표성·효과 검정력을 보장하는 수가 아니다.

| 조사 위치 | 목표 | 확인 이유 |
|---|---:|---|
| 원도심(찜닭골목·문화의거리) | 30팀 | 식사 후 다음 일정과 체험 미이용 이유 |
| 안동역 출발 대기 구역 | 15팀 | 실제 귀가 제약·여행 마무리 지출 |
| 월영교 | 15팀 | 도착 경로·야간 수요·기존 방문 계획 |

당일/숙박, 자가용/비자가용을 기록한다. 비자가용이 너무 적으면 역에서 보충하되 할당 수집한 표본을 도시 전체 교통수단 비율로 해석하지 않는다. 주민·업무·친지방문은 선별 질문에서 구분하고 관광 표본과 따로 집계한다.

장소·시간 블록별로 접근 가능한 매 세 번째 여행팀 등 일정한 규칙으로 접촉한다. 거절·부적격·완료 수를 기록하고 특정 연령·동행형태만 골라 조사하지 않는다. 바쁜 사람이나 열차 탑승 직전인 사람에게 응답을 요구하지 않는다. 이름·전화번호는 기본 설문에 받지 않는다.

### 네 명 역할

- A·B: 방문객 조사 중심. 답사 전 설문 시험 5팀 상당의 내부 역할극으로 질문 누락·소요시간 확인.
- C: 체험 3~4곳과 식당 10~12곳 운영 확인. 이동시간을 감안해 멀리 떨어진 시설의 전수 방문은 하지 않음.
- D: 구간별 이동·대기·운임 기록, 시간표 대조. A·B와 다른 위치에서 설문 보충 가능.
- 두 명뿐이면 관광객 30~40팀, 핵심 체험 2곳, 이동 2구간으로 축소. 상가 60곳 전수 확인은 포기하고 확인한 표본만 보고.

## 5. 방문객 질문: 공통 4~6분, 추가 질문 선택

제안 카드를 보여주기 전에 1~5를 묻는다. 이후 6~8을 묻는다.

1. 안동 거주 여부, 이번 주목적(관광/축제/친지/업무/기타), 조사 장소·시각.
2. 여행팀 총인원·성인/아동, 당일/숙박, 주 이동수단.
3. 안동 도착 일시, 원래 출발 예정 일시, 귀가 목적지, 확정한 기차·버스 시각과 변경 가능 여부.
4. 이미 방문한 곳과 앞으로 갈 곳. 월영교·유료 체험을 원래 계획했는지.
5. 팀 전체의 안동 내 이미 지출한 금액과 앞으로 지출할 계획을 구분: 식음·체험/관람·숙박·안동 내 교통·쇼핑. 안동 왕복 장거리 교통비는 별도. 모름·무응답은 0원으로 입력하지 않는다. 비용을 공유하지 않는 동행이면 응답자가 아는 인원과 지출 범위만 기록.
6. 실제 가격·시간·이동조건을 제시했을 때 A/B/기존 일정 중 무엇을 선택하는지. 실제 예약이나 구매가 아닌 의향임을 표시.
7. 선택한다면 기존 어느 일정을 대체하는지, 안동에서 나가는 시각은 얼마나 달라지는지. 변경 불가능한 귀가편과 충돌하면 ‘일정상 불가’. 숙박객의 저녁 활동시간 증가를 안동 총체류 증가로 바꾸지 않는다.
8. 팀 중 실제 참여 희망 인원, 추가 지불할 금액, 대신 줄일 다른 안동 지출과 원래도 구매할 항목. 미선택 이유는 가격/시간/교통/흥미/아이·동반자/예약제약/기타로 기록.

추가: 코스를 알아보기 쉬웠는지, 안내·예약 위치는 어디가 편한지. 단순 ‘좋다’나 QR 열람을 구매 전환으로 부르지 않는다.

## 6. 시설·교통 기록 항목

### 체험 3~4곳

시설·체험명 / 개인 이용 가능 / 최소 인원 / 정상가·현재 할인가 / 1인·팀·척 단위 / 예약기한 / 시작회차 / 최종접수 / 준비·체험·정리시간 / 회당정원 / 당일 대기 / 평상시 주말과 연휴 운영 / 날씨취소 / 확인일·방법·출처.

표시상 18시 폐점이라도 17시 접수 종료일 수 있다. 시간은 영업 종료와 접수 종료를 따로 받는다. 관람 무료 여부와 유료 체험 여부도 따로 기록한다.

### 식당 10~12곳

기존 표본60에서 코스에 가까운 후보를 선정. 정확한 위치 / 주문마감 / 실제 식사 완료 가능시각 / 중간휴식 / 연휴·평소 영업 차이. 가능하면 관광객 안내에 걸리는 시간, 예약·정산 제약에 대해 의견만 청취한다. 직원 의견을 공식 참여 확약으로 기록하지 않는다. 이 표본으로 원도심 전체 영업 비율을 추정하지 않는다.

### 이동 3구간

원도심→체험시설, 원도심→월영교, 월영교→안동역. 출발·도착 지점 / 호출 시작 / 승차 / 하차 / 도보 도착 / 요금 / 인원 / 교통수단 / 통제·혼잡·날씨를 기록. 가능하면 주요 구간 낮·저녁 각 1회. 소수 실측의 최소~최대는 관측 범위이며 일반적 소요시간의 신뢰구간이 아니다. 축제 셔틀과 평상시 버스를 구분한다.

## 7. 조사 결과를 수치로 바꾸는 방법

### 체류

당일 방문 응답자별로 기존 출발 예정시각과 제안 선택 시 출발 의향시각의 차이를 계산한다. 제안을 선택하지 않으면 변화 0, 자료가 없으면 결측. 다른 일정 대체와 귀가편 제약을 함께 표시한다. ‘전체 조사 대상 당일객’과 ‘코스 선택 의향 당일객’을 따로 보고한다. 숙박객은 추가 활동시간을 별도 지표로 제시한다. 모두 ‘제안 조건에 대한 응답 기반 예상 변화’이며 실제 체류 효과가 아니다.

### 지출

같은 여행팀·인원·기간 기준으로 기존 계획 총지출 B, 제안 반영 총지출 B'를 만든다. 추가 체험·안동 내 교통·식음 지출에서 원래 할 체험과 줄이는 다른 지역 내 소비를 제거한다. 할인·지원금은 관광객 부담과 업체 수취액을 따로 기록하고 지원금을 새 관광객 지출로 더하지 않는다.

- 표본 기준 1인당 계획 지출 = 유효한 팀 지출 합 / 그 지출에 포함된 인원 합.
- 표본 기준 지출 변화율 = (ΣB' − ΣB) / ΣB × 100. 개인별 증가율을 단순 평균하지 않는다.
- 체험 소비 비중 변화 = Σ체험지출' / Σ총지출' − Σ체험지출 / Σ총지출. 결과는 %p로 표시.
- 체험 선택 의향률 = 선택 팀 / 유효 응답 팀. 실제 구매율과 구분한다. 팀 비율을 인원 수에 바로 곱하지 않는다.

이미 결제한 금액과 앞으로의 계획 금액을 분리해 보고하고, 결측으로 제외된 팀 수를 함께 표시한다. 현장 편의표본을 안동 전체의 소비 수준으로 일반화하지 않는다.

### 규모·공급

실제 참여자 100명·500명 등 명시한 운영 규모별로 코스 구성과 체험 정원을 적용한다. 안내 대상자 기준 계산에는 별도의 실제 참여율 가정이 필요하다. 설문 의향을 그대로 구매율로 쓰지 않고 실현률을 추가 가정으로 두며 0% 효과 조건도 점검한다. 낮음·중간·높음은 신뢰구간이나 관측 확률이 아니다.

실현 가능한 이용 인원은 희망 수요, 체험 가능 정원, 차량 좌석·왕복 소요시간으로 계산한 처리량 중 가장 작은 값으로 제한한다. 부족분은 거절·대기·추가 자원으로 표시. 평상시·축제일을 별도 계산한다. 노출 인원·운영일수 근거가 없으면 8개월 총매출을 대표 수치로 내세우지 않는다.

### 도시 기여·신규 방문

도시 체험·문화 카드소비에 대한 기여는 업종 코드와 카드 포괄 범위가 맞는 경우에만 조건부로 환산한다. 맞지 않으면 사업 거래액과 도시 지표를 나란히 제시한다. 참가자 1인당과 데이터랩 방문당을 같은 단위처럼 쓰지 않는다.

신규 관광객 증가율은 이번 현장조사에서 산출하지 않는다. 기본안은 신규 유입 0명으로 두고 기존 방문객의 선택 변화에 집중한다. 별도 잠재 관광객 조사도 의향 근거일 뿐 실제 유입 효과를 검증하지 못한다.
