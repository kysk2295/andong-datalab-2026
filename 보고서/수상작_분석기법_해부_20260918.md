# 수상작은 데이터를 어떻게 "분석"했나 — 사례별 연산 복원 (2026-09-18)

근거: 데이터랩 우수 활용사례 인터뷰 24편 요약(`보고서/수상작_문제해결_분석_20260916.md`), NSI 해부(`부산_야간관광_NSI_성과물_분석.md`), 진행과정 리버스(`보고서/수상작_진행과정_리버스_20260918.md`).

이 문서는 각 작품을 **① 입력(어떤 표를 어떤 단위로 받았나) → ② 결합 키 → ③ 연산(실제로 한 계산) → ④ 판정 기준(무엇을 보고 결론이라 했나) → ⑤ 출력**으로 분해한다.
인터뷰는 결과만 서술하므로 중간 연산은 결과에서 거꾸로 추론한 것이 많다. 추론에는 **(推)**를 붙였다. 확정 인용이 필요하면 원문 인터뷰 페이지를 다시 확인해야 한다.

---

## 0. 먼저 — 24편에서 실제로 쓰인 연산은 일곱 개뿐이다

| # | 연산 | 무엇을 하는가 | 쓴 작품 |
|---|---|---|---|
| R1 | **순위 뽑기** | 한 열을 내림차순 정렬해 상위 N개를 고름 | 옥천, 윤돌섬, 설악, 구례, 소사탕, 제주 |
| R2 | **두 비율의 격차** | 같은 대상의 두 지표 비율을 빼서 어긋남을 만듦 | 인천 의료웰니스, 김포, KAIST, 인천 9경 |
| R3 | **교차표(축 쪼개기)** | 방문/소비를 요일×시간대, 성×연령, 거주지로 분해 | 파주, PM, 강진, 인천 9경, 다움 |
| R4 | **집중률·쏠림 계산** | 상위 k개 항목이 전체에서 차지하는 비중 | 파주, 윤돌섬, NSI, 제주 |
| R5 | **군집(K-Means/DBSCAN)** | 좌표·특성으로 덩어리를 찾음 | KAIST, 성균관대 축제, (우리 M5 유사유형) |
| R6 | **가중합 지수** | 표준화한 여러 지표를 가중치로 합쳐 한 점수로 | 부산 NSI |
| R7 | **목표치 역산** | 필요한 관광객 수를 대체율로 거꾸로 계산 | 옥천, 커뮤니케이션 다움 |

회귀·인과추론·패널분석은 **한 편도 없다**(NSI가 기대효과 추정에 "회귀모델"을 언급하지만 산식·표본은 비공개). 대상작 4편이 쓴 건 R1~R4, 즉 정렬·뺄셈·교차표뿐이다.
→ **심사는 기법 난이도가 아니라 "어떤 표를 왜 그렇게 잘랐는가"를 본다.** 우리가 돌린 OLS·랜덤포레스트는 수상작 기준선을 이미 넘어섰고, 오히려 설명 부담만 커진다.

## 1. 대상·최우수작 해부

### ① 강진 반값여행 (2025 대상) — R3 교차표로 "달력"을 만든 사례

| 단계 | 내용 |
|---|---|
| 입력 | 데이터랩 방문자 3년치(월×성×연령), 자체 빅데이터 플랫폼(유동인구·카드), 상품권 사용액, 군 쇼핑몰 매출 |
| 결합 키 | **시간(월)** 하나. 지역은 강진 고정이라 공간 결합이 없다 |
| 연산 | (a) 월별 방문 3년 평균 → 성수기 식별(3~5월·10월) (b) 축제 개최월과 겹쳐보기 → **불일치 확인** (c) 소비를 관광·레저형 / 생활·상권형 **2분류**로 나눠 각각 어디로 흐르는지 |
| 판정 기준 | "유입이 많은 달 ≠ 축제 달" — 두 분포의 피크가 어긋나는 것만으로 결론 |
| 출력 | 홍보·예산 투입 시점 재배치, 전통시장·쇼핑몰 연계 |

**핵심**: 분석이 정한 건 사업이 아니라 **타이밍**이다. 3년 평균을 쓴 이유는 단년 변동을 지우기 위함(推). 소비를 두 갈래로 나눈 것이 결정적인데, "관광소비를 늘린다"가 아니라 "관광형은 축제로, 생활형은 시장·쇼핑몰로"라는 **처방 분기**를 만들었기 때문이다.
성과 서술은 방문 +43만·소비 69억·승수 240억인데, 이건 분석이 아니라 집행 실적이고 비교집단이 없다.

### ② 옥천 관광주민증 (2023 대상) — R1 순위 + R7 역산

| 단계 | 내용 |
|---|---|
| 입력 | 데이터랩 인기 관광지 순위, 맛집(음식점) 순위, 인구감소 관광대체율 계산기 |
| 결합 키 | 관광지·업소 **명칭/위치** |
| 연산 | (a) 인기 관광지 순위에서 **유료 시설만 필터** → 혜택업소 1순위 (b) 맛집 순위 순서대로 섭외 (c) 대체율 계산기로 "주민 1명 소비 = 숙박객 36명 = 당일객 76명" 역산 |
| 판정 기준 | 순위 상위 = 혜택 붙일 가치 있음. 유료 필터를 건 이유는 **할인이 의미를 갖는 곳**이어야 하기 때문 |
| 출력 | 혜택업소 15곳, 사용 14,292건 |

**핵심**: 여기서 배울 건 (a)의 **필터 한 줄**이다. 인기순위를 그대로 쓰지 않고 "유료"라는 조건을 걸어, 정책 수단(할인)과 데이터(방문 인기)를 맞물리게 했다. 우리 릴레이 1단계 식당 선정도 "원도심 + 객단가 4만 근처 + 저녁 영업"처럼 **수단과 맞물리는 필터**를 명시해야 같은 급이 된다.
(c)의 역산은 24편 중 목표치를 숫자로 만든 유일한 방법이다. 산식(推): 주민 1인 연간 소비액 ÷ 관광객 1인 1회 소비액, 숙박·당일 구분.

### ③ 관광지 PM 안전관리 (2024 대상) — R3 교차표 두 개를 겹친 사례

| 단계 | 내용 |
|---|---|
| 입력 | 데이터랩 방문자 + GIS, TAAS 사고통계, 공유 PM 이용 로그 |
| 결합 키 | **공간(GIS 좌표/행정구역) × 시간(시간대)** — 24편 중 2중 키를 제대로 쓴 유일한 축 |
| 연산 | (a) 방문자 특성으로 청년층 밀집 지역 추출 → '여가존·교통존' 유형화 (b) PM 이용 시간대 분포(15~21시)와 사고 시간대 분포(16~22시)를 **겹쳐서** 개입 시각 도출 (c) 지역×시간 교집합에 매체(버스정보안내기·편의점 LCD) 배치 |
| 판정 기준 | 두 분포의 **겹치는 구간** = 개입 지점. 인과 검증 없음 |
| 출력 | 시간대별 캠페인, 교육 108,497명 |

**핵심**: "수요 분포 × 위험 분포를 겹쳐 교집합에 개입한다"는 것이 안전 계열(NSI·해경·관광경찰대) 전체의 공통 틀이다. 우리 식으로 옮기면 **"유출 시각 분포 × 콘텐츠 운영 시각 분포"를 겹쳐 빈 구간을 찾는 것**이고, 안동역 전 열차 승차 피크(14–15시, 17–18시)와 원도심 영업 종료 시각을 같은 그림에 올리면 그대로 성립한다. 아직 우리가 안 그린 그림이다.

### ④ 인천 의료·웰니스 (2025 최우수) — R2 격차로 문제를 열고, 세분화로 처방

| 단계 | 내용 |
|---|---|
| 입력 | 외래객 입국 통계, 인천 방문율, 진료과목별 수요, 국가별 웰니스 선호, 여행경로·예약채널 |
| 결합 키 | **국적** |
| 연산 | (a) 68.5%(입국) vs 6.3%(방문) 격차 = 문제 선언 (b) 진료과목 수요를 **타 시도와 비교**해 인천만의 구조(대학·종합병원 편중) 확인 (c) 국적별로 쪼개 각각 다른 이유를 붙임 — 몽골: 암 사망률 1위(외부 통계), 러시아: 직항 없는데 방문 증가(이상 신호), 독일·중국·일본: 선호 항목 차이 (d) 여행경로에서 OTA 채널 도출 |
| 판정 기준 | 격차 + 국적별 이상치. 회귀 없음 |
| 출력 | 국적별 세일즈콜·팸투어·채널 전략 |

**핵심**: (c)가 이 작품의 실력이다. 하나의 문제를 국적이라는 축으로 쪼개니 **처방이 자동으로 여러 개** 나왔다. 축 하나를 잘 고르면 분석량 없이 처방이 늘어난다.
약점은 이미 정리한 대로 문제 지표(방문율)와 성과 지표(환자 수)의 불일치다.

## 2. 우리와 형식이 겹치는 작품 해부

### ⑥ 부산 NSI (2025 우수) — 유일한 R6 가중합 지수

| 단계 | 내용 |
|---|---|
| 입력 | 구·군별 범죄 발생, CCTV 설치 밀도, 야간 관광활동, 야간 관광소비, 관광활성화지수, 교통 접근성 |
| 결합 키 | **행정구역(16개 구·군)** — 모든 지표를 같은 단위로 맞춘 것이 작업의 절반(推) |
| 연산 | (a) 단위가 다른 지표를 **표준화**(min-max 또는 z, 방식 비공개) (b) 가중합 NSI = 범죄 .35 + CCTV .25 + 활동 .15 + 소비 .15 + 활성화 .10 (c) X=야간 수요, Y=NSI로 **2축 매트릭스** → 4분면 분류 (d) 분면별 처방 |
| 판정 기준 | 4분면 위치. 특히 "수요 높고 안전 낮음"=최우선 |
| 출력 | 지수·매트릭스·우선지역·처방·기대효과 |

**핵심과 약점**: 가중치 .35/.25/.15/.15/.10의 근거가 공개되지 않았다. 지수 작품의 생사는 **가중치 정당화와 민감도**인데 둘 다 없다. 우리 M5 진단점수를 만들 때 반드시 채워야 할 칸: (i) 가중치를 왜 그렇게 뒀는지 한 줄, (ii) 가중치를 흔들어도 순위가 유지되는지(우리는 이미 지역선택 스크리닝에서 이 작업을 했다 — **그 자체가 NSI보다 나은 부분**), (iii) 결측 지역 처리.

### ⑦ 김포 5味로드 (2025 우수) — R2 격차 + 설문으로 요인 추림

| 단계 | 내용 |
|---|---|
| 입력 | 내비 음식 검색 비중(59.9% vs 경기 51%), 관광매출 업종 비중, 체류시간 1,279분, 관광지 간 이동경로, 자체 설문 |
| 결합 키 | 관광지·지역 |
| 연산 | (a) 검색 비중과 매출 비중의 **방향 불일치** = 문제 (b) 체류는 긴데 소비가 안 붙음 → 원인 후보를 '연결 부족'으로 좁힘 (c) 이동경로 + 설문을 겹쳐 "체류를 늘리는 요소 / 소비로 잇는 요소"를 **분류** (d) 요소들을 코스로 묶음 |
| 판정 기준 | 설문 응답 분류 + 경로 인접성(推) |
| 출력 | 5味 코스, 시범 4,500명 |

**핵심**: (b)의 논리가 우리와 정확히 같다("오는데/머무는데 안 쓴다 → 연결 문제"). 그래서 **차별화 부담이 가장 큰 작품**이다. 다만 김포는 원인을 설문으로 좁혔고, 우리는 P2·P4라는 **행동 관찰**로 좁힌다는 차이를 명시할 수 있다.
약점: 성과가 참여자 체류 2.1→3.5시간인데 참여자만 잰 값이라 자기선택이 섞였고, 문제 지표(식음료 매출 비중)로 닫지 않았다.

### ⑧ KAIST 대전 (2024 우수) — 유일한 좌표 군집 R5

| 단계 | 내용 |
|---|---|
| 입력 | 내비 검색 목적지(좌표), 20대 비율 25.5%, 무박 비율, 하천·바다 축제 24개의 숙박업 소비 비율 |
| 결합 키 | **좌표** |
| 연산 | (a) 검색 목적지에 **K-Means**(구 단위 덩어리) + **DBSCAN**(밀도 기반, 임의 형태 덩어리) 동시 적용 (b) 갑천 주변에 상위 목적지 밀집 확인 (c) 사이언스페스티벌을 **같은 유형 축제 24개 안에서** 숙박 소비 비율로 순위 매김 → 하위권 (d) 설문 288명 |
| 판정 기준 | 군집 밀도 + 동류 집단 내 순위 |
| 출력 | 갑천 야간 포토스팟·축제 플랫폼 제안 |

**핵심**: (c)의 "**같은 유형 24개 안에서 비교**"가 우리 M5 유사지역 비교(공주·부여·문경·남원·충주·강화)와 같은 수법이다. 두 알고리즘을 같이 쓴 이유는 K-Means가 구형 덩어리만 찾기 때문(하천변처럼 길쭉한 밀집은 DBSCAN이 잡는다)(推). 우리가 좌표 데이터(내비)를 아직 군집에 안 쓴 건 빈칸이다.
약점: 결론이 설문 의향 52.6%이고, 신규 공원 조성이라 구축비·주체가 없다.

### ⑨ 파주 통일동산 (2022 대상) — R3+R4로 병목 경로 복원, 24편 중 가장 깔끔

| 단계 | 내용 |
|---|---|
| 입력 | 내비 검색 목적지 순위(헤이리·프로방스 1위), 거주지 분포(수도권 92.3%), 요일×시간 집중률(주말 14~18시), 주차장 15곳·게이트 10곳 |
| 결합 키 | **출발지→목적지 경로** |
| 연산 | (a) 목적지가 소수에 쏠림(R1) (b) 출발지가 수도권에 쏠림(R4) → **진입 IC가 하나로 수렴**한다는 추론 (c) 시간 집중률로 그 수렴이 **언제** 일어나는지 (d) 세 쏠림을 합쳐 "같은 IC → 같은 사거리 → 1번 주차장"이라는 **단일 경로 서사**로 복원 |
| 판정 기준 | 세 분포가 모두 한 점을 가리킴 |
| 출력 | 주차장·게이트 사전 안내로 분산 |

**핵심**: 이게 24편 중 **가장 배울 게 많은 분석**이다. 새 데이터도, 어려운 기법도 없다. 순위·거주지·시간대 세 개의 흔한 표를 **"한 사람이 실제로 지나가는 순서"로 재배열**했을 뿐인데 병목이 물리적 지점으로 특정됐다.
우리에게: 안동역 도착 시각 분포 → 원도심 체류 → 저녁 이동수단 → 숙박/귀가를 한 줄로 재배열하면 같은 그림이 된다. 데이터는 이미 다 있다(안동역 시간대별 승하차, 카드 업종별, 체류시간). **"시간표 계산이지 실측 아님" 표기는 유지.**

### ⑩ 커뮤니케이션 다움 (2022 대상) — R7 목표 역산 + 채널 세분화

| 단계 | 내용 |
|---|---|
| 입력 | 인구감소 관광대체 소비규모, 체류시간, 연령 분포 |
| 연산 | (a) 대체율로 **투어 목표 인원 역산** (b) 연령대(20대 / 50~60대)별로 홍보 채널을 갈라 배정 — 대학 단톡방 vs 지역신문·당근마켓·지하철 (c) 동선 설계: 투어 **종료 지점을 버스정류장 앞**, 마지막 장소를 카페로 |
| 출력 | 293명, 목표 대비 200%, 30%가 외지인 |

**핵심**: (c)는 데이터 분석이 아니라 **설계 원리**인데, 릴레이의 인계 지점 설계에 그대로 적용된다. "끝나는 곳을 다음 소비 앞에 둔다."
목표 대비 200%라는 성과 표현이 가능했던 이유는 (a)에서 **목표를 숫자로 먼저 박았기** 때문이다. 우리 ③ 계산기도 "효과 범위"만 내지 말고 **목표값 한 개**를 박아두면 성과 서술이 쉬워진다.

### ⑪ 윤돌섬 ECO DIVE (2025 우수) — R1 + 키워드 + 규정 해석

| 단계 | 내용 |
|---|---|
| 입력 | 거제 인기 관광지 순위, 해수욕장 이용객, 검색 키워드(스노클링·카약), 무인도서 관련 법령 |
| 연산 | (a) 쏠림 확인(학동몽돌·바람의언덕) (b) 검색 키워드로 **수요가 있는 활동 종류**를 특정 (c) 출입금지 조항의 예외(보호조치 목적)를 찾아 정화활동을 필수 요소로 (d) 보상 = 지역사랑상품권 |
| 출력 | 구조라 검색 +78%, 참여자 +33%, 체험객 소비 = 평균의 2.4배 |

**핵심**: (b)의 용법 — **검색 키워드를 "무엇을 만들까"의 답으로 쓴다.** 우리는 검색 데이터를 문제 진단(월영교 −26.9% 등)에만 썼고, 콘텐츠 설계 근거로는 아직 안 썼다.
약점: 2.4배는 참여자 vs 일반 평균이라 선택편향.

### ⑫ 성균관대 축제 분석 (2023) — R5 군집으로 성공요인

| 단계 | 내용 |
|---|---|
| 입력 | 지역축제 방문객, 예산, 일평균 방문객, 개최지·유형 속성 |
| 연산 | (a) **방문객/예산**이라는 파생지표 생성 (b) 일평균 방문객과 함께 성공·실패 군집 (c) 변수 중요도로 요인 추출 |
| 출력 | 특산물형·비수도권·관광지 개최 = 성공, 전통형 = 저조 |

**핵심**: (a)의 파생지표 한 줄이 분석 전체를 성립시켰다. **"효율(투입 대비 산출)"을 만들면 크기가 다른 대상을 한 줄에 세울 수 있다.**
우리 대응물: 탈춤축제를 56개 문화관광축제 안에 세운 작업(일평균 11위·외지인 비율 36.3%·소비 38위)이 이미 같은 계열이고, 오히려 더 정교하다. 다만 "전통형 저조"는 **우리 안동 포지셔닝(전통)과 정면으로 부딪히는 선행 결과**라 제출문에서 한 번은 반박하거나 우회해야 한다.

## 4. 우리 분석과 대조 — 무엇이 남았나

| 수상작이 한 것 | 우리 상태 |
|---|---|
| R1 순위+필터로 **섭외 순번** 만들기(옥천) | ✗ 릴레이 1단계 식당 선정 기준이 아직 문장뿐. 데이터 필터로 바꿔야 함 |
| R2 격차로 문제 열기 | ✓ 방문 +5.6% vs 방문당 소비 −2.8%. 이미 수상작 수준 |
| R3 교차표로 **개입 시각** 정하기(PM·파주) | △ 안동역 시간대 데이터는 있으나 영업·콘텐츠 운영시각과 겹쳐 그린 적 없음 |
| R4 쏠림 + 경로 복원(파주) | ✗ **가장 비용 대비 효과가 큰 빈칸**. 새 데이터 없이 오늘 만들 수 있음 |
| R5 좌표 군집(KAIST) | ✗ 내비 좌표 데이터 보유, 군집 미실시 |
| R5 동류집단 내 순위(KAIST·성균관대) | ✓ 축제 56개·유사지역 15곳 비교 완료. 오히려 우위 |
| R6 가중합 지수(NSI) | △ M5 설계 중. 가중치 근거·민감도는 우리가 이미 하던 방식이라 우위 확보 가능 |
| R7 목표치 역산(옥천·다움) | ✗ 관광대체율 계산기 미사용. ③ 계산기에 **목표값 한 개**를 박을 근거 |
| 회귀·모델 | 우리만 함. 수상작 기준 초과 — 발표에서 주역으로 쓰지 말고 **부록**으로 |

**우선순위 제안(남은 12일 기준)**
1. **R4 경로 복원 한 장**(파주식). 보유 데이터만으로 가능, 심사 '데이터 활용도 30'에 직결.
2. **R7 목표치 역산**. 계산기에 목표 한 줄이 생기면 ④ 성과측정이 "달성/미달"로 서술된다.
3. **R1 필터 명시**. 옥천의 '유료 필터'처럼, 우리 각 단계 대상 선정 규칙을 데이터 조건으로 적는다.
4. R5 좌표 군집은 시간이 남을 때. 없어도 대상작들은 다 받았다.
