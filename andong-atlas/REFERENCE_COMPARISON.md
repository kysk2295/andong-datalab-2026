## 실제 자료와 표현의 경계

- 서울의 고층 밀도를 안동에 임의로 옮기지 않는다. 실제 건물 윤곽과 연구 추정 높이의 도시 간 차이가 화면에 남는다. GBA는 CC BY-NC 4.0이며 최신 현황·실측 자료가 아니다.
- 창문·옥상 설비·수목·차량·사람은 스타일 표현이다. 실시간 교통, 건축 외관 전수 복원, 실제 수목 위치를 주장하지 않는다. 버스·선박의 가로 크기는 주변 도로·교량에 맞춰 축소했다.
- 팝업/거점은 제안 위치에 놓은 설명 모형이다. 팝업 대표점은 지형 경사를 확인해 월영교 서측 주차장 권역(OSM76992439)으로 보정했고 모형 가로 크기를 조정했다. 팝업 표시 범위를 약25.2×18m로 축소하고 주차장 내 DEM 경사가 작은 128.758095/36.576700으로 조정했다. 수평 받침은 시각화이며 시공 계획이 아니다. 기존 분석 기대효과 수치를 바꾸지 않았다.
- 전역의 넓은 행정권역과 도심 상세의 범위는 다르다. 고밀도 도시 질감은 기본 진입 화면을 도심 전체로 설정해 확인할 수 있다.
- 레퍼런스의 서울 고유 랜드마크·산별 등산로·모든 선종을 복제하지 않는다. 전역 나무는 가벼운 모형이고 상세 영역에서 수관·겨울 가지를 강화했다.

사용자가 요청한 90%를 객관적 측정치로 표기하지 않는다. 서로 다른 지형·건물 데이터라 픽셀 일치율을 품질 점수로 쓸 수 없으며, 위 항목별 실제 화면과 동작을 검수 기준으로 삼았다. 이전판의 가장 큰 차이였던 건물 누락, 밝고 단순한 외벽, 듬성한 숲, 불연속 차량 이동을 보완했다.

## 2026-09-28 추가 육안 검수

기존판은 객체 수가 있어도 확대 화면에서 사람·차량이 드물고 건물 색이 구분되지 않았다. 이번에는 Chrome에서 원본 강남·서울숲을 직접 열어 비교하고, 안동 서동문로·웅부공원에서 확대·회전하며 확인했다. 고정된 공원 시점의 서로 다른 시각 화면에서 차량 위치와 보행자 위치 변화, 조경 동선·벤치·외벽 바닥을 확인했다. 객체 수 자체나 픽셀 일치율을 완성도 증거로 삼지 않는다.

보완한 산책 공간은 공개된 공원 경계에 근거한 연출이며 현장 조경과 일치한다고 주장하지 않는다. 경사 지역의 4배 표고 강조와 위성 추정 높이 때문에 높은 기초벽이 남을 수 있고, 역사 건축물 고유 외관은 일반 건물 표현으로 남아 있다.
